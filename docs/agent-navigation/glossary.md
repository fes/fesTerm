- **application coordinator** (aka coordinator, app coordinator) — The composed app-level owner that serializes actions, cleanup, and state transitions off the UI thread. `docs/automation-design.md` → [automation](automation.md)
- **bounded ingest** (aka ingest budget, global ingest budget) — A shared terminal-ingest budget that limits per-update work and rotates busy sessions fairly across a window. `docs/adr/0079-global-terminal-ingest-budget.md` → [terminal-core](terminal-core.md)
- **cell footprint** (aka cell memory charge, compact cell charge) — The in-memory accounting for compact terminal cells and retained content required to keep recovery bounded. `docs/adr/0081-compact-cells-with-stable-recovery-charges.md` → [terminal-core](terminal-core.md)
- **daemon-owned lease** (aka daemon lease, session lease) — A protected session lease owned by the local daemon instead of a transient GUI tab. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **Direct2D** (aka Direct2D backend, D2D) — The explicit Windows native renderer path that queues native geometry and textures through Direct2D. `crates/festerm-windows-direct2d/src/renderer.rs::Renderer` → [terminal-ui](terminal-ui.md)
- **East Asian width** (aka east-asian width, wide char width) — The width policy that assigns one or two columns to a completed grapheme sequence. `docs/adr/0026-grapheme-width-and-color-emoji-fallback.md` → [terminal-core](terminal-core.md)
- **enrolled HOST** (aka enrolled host, host enrollment) — An explicitly enrolled host using owner-key proof and native-vault-backed trust before credentials are used. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **generation** (aka daemon generation, session generation) — The monotonic identity of a live daemon or attachment that fences stale reuse and revocation. `docs/host-protocol.md` → [sessions](sessions.md)
- **grapheme** (aka grapheme cluster, cluster) — A terminal text cluster that grows incrementally across UTF-8 fragments and owns display width. `crates/festerm-core/src/unicode.rs::grapheme_width` → [terminal-core](terminal-core.md)
- **GUI action graph** (aka action map, gui state graph) — The reviewed, testable user-flow graph that names terminal and host transitions with their verification edges. `docs/gui-action-graph.md` → [app-commands](app-commands.md)
- **HOST** (aka host protocol, dev tunnel host, host-based Dev Tunnel, HOST tunnel) — The host-oriented protocol that authenticates a tunnel, verifies owner identity, and routes session control. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host policy source** (aka protected policy source, policy source) — The native policy component that validates current ownership, receipts, and revocation before host admission. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host runtime** (aka runtime service, host service runtime) — The authenticated bridge runtime that serves a host connection, inventory, and protected session control. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host service** (aka configured host service, host setup) — A configured machine-side service instance that supplies authorized inventory, session creation, and routing. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **Job Object** (aka windows job object, kill-on-close job) — The Windows process-group object that can terminate a child tree when a parent closes or shuts down. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **local PTY** (aka local pty, pty worker) — The local process-backed terminal device used for ordinary shell sessions before persistence or remote routing. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **logical history** (aka retained history, history rows) — Ordered primary-screen lines with stable identities used for reflow, search, and viewport anchoring. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **native vault** (aka secret store, keychain store) — The platform-native secret boundary that stores opaque credentials outside TOML and app state. `docs/adr/0016-native-secret-store-boundary.md` → [config-secrets](config-secrets.md)
- **owner binding** (aka owner consent, verified binding) — The protected binding between a host action and the verified local owner identity and key. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **owner proof** (aka verified owner binding, owner key proof) — Cryptographic proof binding a host request to the correct protected owner key before action. `docs/host-protocol.md` → [ssh-sftp](ssh-sftp.md)
- **owner-auth** (aka owner auth, owner-auth feature) — The opt-in authentication feature that performs challenge-and-proof exchange before a host action is admitted. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **persistent daemon** (aka persisted daemon, sessiond daemon) — A detached local helper that keeps a shell alive across frontend exits and reconnects. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **profile hosting** (aka installed hosting, hosted profile) — A host-oriented workflow where a configured machine shares or creates sessions through a saved profile. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **public host recipe** (aka portable host recipe, host recipe, portable recipe, host profile recipe) — Portable metadata describing a host, launch details, and lifetime without including protected credentials or approval. `docs/configuration.md` → [config-secrets](config-secrets.md)
- **recovery mirror** (aka authoritative mirror, daemon mirror) — The daemon-owned terminal state used to restore exact terminal behavior after reattach. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **recovery snapshot** (aka snapshot prelude, attach snapshot) — A bounded serialized terminal image sent before live output on protocol-v2 attach. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **runtime capability advertisement** (aka capability advert, issuance epoch) — The advertised host runtime state that carries the current protected issuance epoch for create and ensure actions. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **save gate** (aka config save gate, save-latch) — The app-side guard that blocks further config writes after an indeterminate or failed save attempt. `docs/configuration.md` → [config-secrets](config-secrets.md)
- **scrollback** (aka history buffer, terminal history) — Retained primary-screen history kept within a configured memory budget and stable across resize. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **session lifecycle** (aka lifecycle state, session state) — The ordered states a session traverses across startup, attachment, disconnect, and terminal completion. `crates/festerm-session/src/lib.rs::SessionLifecycle` → [sessions](sessions.md)

- **SFTP** (aka secure file transfer, remote file manager) — A first-class remote file surface used to browse, transfer, and resolve collisions over an authenticated session. `docs/sftp-ui-design.md` → [ssh-sftp](ssh-sftp.md)
