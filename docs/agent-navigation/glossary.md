- **app-owned terminal boundary** (aka terminal boundary, app boundary) — The application-level boundary where terminal state is observed or mutated by the broker, not by scripts or adapters. `docs/automation-design.md` → [automation](automation.md)
- **attachment epoch** (aka automation epoch, safe-attach epoch) — Shared epoch value used to reject stale or replaced backend attachments and automation observers. `docs/automation-design.md` → [automation](automation.md)
- **authoritative terminal snapshot** (aka recovery state, state snapshot) — The daemon's canonical terminal clone that must be restored instead of replaying raw bytes. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **authority kernel** (aka automation broker, broker kernel) — Application-owned authorization layer that validates requests and gates all automation effects and disclosures. `docs/automation-design.md` → [automation](automation.md)
- **bounded logical scrollback** (aka logical history, history budget) — Ordered retained logical lines that preserve geometry and are evicted by a strict byte cap. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **challenge nonce** (aka fresh nonce, owner challenge) — Fresh random challenge used to bind a proof to one real channel, host key, and current policy state. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **current-policy lease** (aka policy guard, verifier lease) — Short-lived policy guard that locks the current owner policy while fresh approvals and operations are checked. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **current-user DACL** (aka user ACL, pipe ACL) — Current-user access control list used to keep named pipes and runtime files private to the right local user. `docs/adr/0025-native-local-session-persistence-daemon.md` → [desktop-platform](desktop-platform.md)
- **DECSET** (aka mode set, VT mode) — Terminal mode-setting operation that toggles behaviors such as reverse wraparound or focus reports. `COMPATIBILITY.md` → [terminal-core](terminal-core.md)
- **Direct2D** (aka D2D, Direct2D path) — Windows API path used to batch terminal compositing on eligible WARP or limited hardware surfaces. `validation/direct2d/README.md` → [terminal-ui](terminal-ui.md)
- **East Asian width** (aka ambiguous width, wide-cell policy) — Cell allocation policy that defaults ambiguous East Asian code points to one cell and keeps width deterministic. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **exact target reference** (aka exact target, target identity) — Concrete target identity that a workflow must name rather than a wildcard or active-tab alias. `docs/automation-design.md` → [automation](automation.md)
- **generation** (aka attachment generation, session generation) — Monotonic generation identifier that pins a live daemon or transport attachment to the correct instance. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **grapheme** (aka extended grapheme, cluster) — User-perceived Unicode segment whose width and cell ownership are fixed by the terminal core. `docs/adr/0026-grapheme-width-and-color-emoji-fallback.md` → [terminal-core](terminal-core.md)
- **GUI action graph** (aka action graph, workflow graph) — Traversal map of user-visible GUI edges and recovery paths used to track validation coverage. `docs/gui-action-graph.md` → [app-shell](app-shell.md)
- **HOST** (aka host service, host v1) — Host-oriented dev-tunnel service contract that binds explicit host identity, owner proof, and session routing. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host inventory** (aka session inventory, host session list) — List of host-provided sessions and their metadata that is discovered separately from terminal access itself. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-based Dev Tunnel** (aka dev tunnel host, host tunnel) — Explicit host-scoped dev-tunnel workflow that starts from account-scoped host search and per-host session creation. `docs/ui-state-narrative.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-key trust** (aka persistent trust, known-host trust) — Explicit, persisted trust for a host key that is not treated as ordinary config metadata. `docs/configuration.md` → [ssh-sftp](ssh-sftp.md)
- **Job Object** (aka KILL_ON_JOB_CLOSE, job breakaway) — Windows job that enforces process-tree teardown and breakaway rules for detached session helpers. `crates/festerm-windows-job/src/lib.rs` → [desktop-platform](desktop-platform.md)
- **native vault** (aka secret store, keyring store) — Platform-native store that holds opaque secret references and keeps secrets outside TOML configuration. `docs/host-protocol.md` → [config-secrets](config-secrets.md)
- **owner authentication** (aka channel auth, owner-auth) — Process that verifies the local owner and host binding on a live channel before granting authority. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **owner binding** (aka host binding, owner proof binding) — Exact host/account/installation binding that a proof must match before granting owner authority. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **owner enrollment** (aka host enrollment, owner key store) — Protected local enrollment of a host owner key and account binding before host-scoped authorization is accepted. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **owner proof** (aka channel proof, owner auth) — Cryptographic proof that the live SSH channel is bound to the correct local owner and host identity. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **profile hosting** (aka hosted runtime, profile runtime) — Installed helper/runtime staging for hosted profiles and signed runtime assets separate from the app binary. `app/festerm/src/profile_hosting_stage.rs` → [desktop-platform](desktop-platform.md)
- **protected headless store** (aka headless file store, explicit file store) — Explicit file-based owner credential store with stronger origin restrictions than the portable config path. `docs/host-protocol.md` → [config-secrets](config-secrets.md)
- **recovery mirror** (aka daemon mirror, authoritative mirror) — Daemon-owned terminal state kept in sync with PTY output so a reconnect restores the same parser/state. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **recovery snapshot** (aka attach prelude, snapshot prelude) — Bounded serialized terminal state sent before live output on protocol-v2 attach. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **scrollback** (aka terminal history, retained history) — Primary-screen rows retained beyond the visible viewport and bounded by a configured byte budget. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **session lifecycle** (aka terminal lifecycle, session state) — The tracked phases of a session from creation through attach, shutdown, and recovery or replacement. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **session takeover** (aka steal-on-reconnect, newest-client win, takeover policy, new attach wins) — Policy where the newest attaching client takes over a live daemon-held session after forced detach. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **sessiond** (aka local daemon, persistence daemon) — Standalone local daemon that keeps one PTY shell alive and reattaches after the GUI exits. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **SFTP** (aka remote file access, file transfer) — Graphical remote-file surface over SSH that provides browsing, transfer, and collision handling. `docs/sftp-ui-design.md` → [ssh-sftp](ssh-sftp.md)
- **terminal-ingest budget** (aka shared ingest budget, window ingest cap) — Per-window cap that bounds UI-thread terminal parsing and rotates work across sessions. `docs/adr/0079-global-terminal-ingest-budget.md` → [terminal-ui](terminal-ui.md)
- **terminal_replies_owned_by_backend** (aka backend-owned replies, reply ownership) — Backend-owned terminal replies are generated by the transport backend instead of the frontend terminal clone. `crates/festerm-session/src/lib.rs` → [sessions](sessions.md)
- **traceability** (aka validation trace, registry mapping) — Machine-checked mapping from requirements and ADRs to tests, manual evidence, and edge IDs. `docs/development-governance.md` → [automation](automation.md)

- **WARP** (aka Microsoft WARP, software raster) — Microsoft software rasterizer used as a Windows fallback path for terminal composition and validation. `validation/direct2d/README.md` → [terminal-ui](terminal-ui.md)
- **workflow digest** (aka bundle digest, manifest digest) — Immutable hash bound to an automation invocation that limits what a workflow may do and what it can read. `docs/automation-design.md` → [automation](automation.md)
