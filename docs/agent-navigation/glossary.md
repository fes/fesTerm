- **cell footprint** (aka per-cell charge) — Per-cell memory charge preserved across recovery and history accounting so schema and eviction behavior remain stable. `docs/adr/0081-compact-cells-with-stable-recovery-charges.md` → [terminal-core](terminal-core.md)
- **daemon-owned leases** (aka session leases) — Leases and generation fencing owned by the local daemon so API calls cannot replay stale attach or create authority. `docs/host-protocol.md` → [sessions](sessions.md)

- **Dev Tunnel bridge** (aka bridge relay) — The host-side bridge that routes authenticated inventory, session creation, and attachment lifetimes through the host service. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **Direct2D** (aka D3D11-on-12) — Optional Windows x64 native terminal paint path that keeps ordinary egui rendering for unsupported cases and failures. `docs/adr/0039-opt-in-direct2d-terminal-composition.md` → [desktop-platform](desktop-platform.md)
- **East Asian width** (aka ambiguous width) — Width policy that defaults East Asian ambiguous characters to one cell unless a separate configurable policy is selected. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **enrolled HOST** (aka verified host) — A host that has a protected owner enrollment, reviewed consent, and a stable identity before remote session creation. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **generation** (aka daemon generation) — Nonzero daemon incarnation identifier used to pin reattach, rescue, and stale-creation checks to a single live session. `docs/configuration.md` → [sessions](sessions.md)
- **grapheme** (aka extended grapheme) — A terminal text unit that may include combining marks, emoji sequences, and width-changing scalars while preserving cell geometry. `docs/adr/0026-grapheme-width-and-color-emoji-fallback.md` → [terminal-core](terminal-core.md)
- **GUI action graph** (aka action graph) — Stable workflow map of UI actions, edges, and validation evidence used to reason about changes and regressions. `docs/gui-action-graph.md` → [app-commands](app-commands.md)
- **HOST** (aka host runtime) — The verified host-side protocol and runtime boundary that authenticates owner proof and session lifecycle operations. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host inventory** (aka authorized inventory) — Protected session metadata filtered by ownership, sharing, and revocation before it is published or used for attachment. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host service** (aka shared host setup) — Configured host-side runtime that owns trust, identity, and service registration for remote access and session attachments. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-based Dev Tunnel** (aka HOST tunnel) — Explicit host service model that binds connection, trust, session inventory, and local daemon ownership to a verified host. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **issuance epoch** (aka admission epoch) — Monotonic host-side epoch that binds each create or ensure operation to the current protected issuance namespace. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **Job Object** (aka KILL_ON_JOB_CLOSE) — Windows process-group boundary used to ensure local shell children die when fesTerm closes a session. `crates/festerm-windows-job/src/lib.rs` → [desktop-platform](desktop-platform.md)
- **known host fingerprint** (aka known_host_fingerprint) — Exact host:port SHA-256 fingerprint used to accept a matching SSH server key without prompting. `docs/adr/0020-persistent-host-key-trust.md` → [ssh-sftp](ssh-sftp.md)
- **local session persistence** (aka durable local session) — A local daemon-backed session that survives frontend exit and can reattach to the same PTY/ConPTY shell. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **logical history** (aka retained history) — Ordered primary-screen logical lines that survive resize, selection remapping, and viewport anchoring. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **native vault** (aka protected store) — Platform-native secret storage used for owner keys and protected policy state instead of plain config data. `docs/adr/0084-host-based-dev-tunnels.md` → [config-secrets](config-secrets.md)
- **OSC 8 hyperlink** (aka OSC 8) — Link metadata for HTTP(S) URLs or local file targets that is preserved and acted on only through explicit UI intent. `COMPATIBILITY.md` → [terminal-core](terminal-core.md)
- **owner binding** (aka host binding) — Association between host, principal, and action that stamps lease and operation authority for a protected creation or attach. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **owner proof** (aka owner binding proof) — Cryptographic owner challenge and proof exchanged on the pinned SSH channel before terminal or control admission. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **persistent host-key trust** (aka known hosts) — Saved SSH host public-key fingerprint that silences future prompts for the same host and port until explicit revocation. `docs/adr/0020-persistent-host-key-trust.md` → [ssh-sftp](ssh-sftp.md)
- **primary-screen history** (aka visible history) — The retained primary buffer and viewport state that stay separate from the alternate screen and its no-history model. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **profile hosting** (aka remote profile host) — Explicit host profile catalog and remote creation model gated by verified owner policy and exact-session state. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **protected policy** (aka current policy) — Verified native authorization state rechecked before each protected host or session action so stale policy cannot grant access. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **recovery mirror** (aka authoritative mirror) — Daemon-owned terminal snapshot used to reattach without replaying stale replies or side-effectful input. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **remote session creation** (aka session creation) — Explicit remote command that creates a new persistent or temporary shell only after verified owner consent and generation checks. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **scrollback** (aka history buffer) — Retained terminal output above the visible screen, tracked as logical history with a configured memory bound. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **sessiond** (aka persistence daemon) — Standalone local daemon that owns one PTY/ConPTY session and exposes a local-only IPC CLI for detach, attach, and inventory. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **SFTP** (aka secure file transfer) — SSH subsystem for authenticated remote filesystem access, transfer, and text-mode session commands. `docs/adr/0028-text-mode-sftp-session-tabs-via-russh-sftp.md` → [ssh-sftp](ssh-sftp.md)
- **shell lifecycle ownership** (aka daemon-owned shell) — The daemon owns the detached shell process and survives client or UI exit while preserving the exact generation and terminal state. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **traceability** (aka validation traceability) — Machine-checked mapping from requirements and ADRs to tests and manual evidence required before handoff. `docs/development-governance.md` → [automation](automation.md)
- **WARP** (aka Windows Advanced Rasterization) — Software-rendered Windows path that qualifies a supported Direct2D terminal route without changing ordinary terminal semantics. `docs/adr/0039-opt-in-direct2d-terminal-composition.md` → [desktop-platform](desktop-platform.md)
- **workflow bundle** (aka automation bundle) — User-selected JSON workflow payload that a desktop automation run validates and executes under a bounded approved scope. `docs/automation-design.md` → [automation](automation.md)
