- **East Asian width** (aka ambiguous width, wide-cell policy) — The width policy for Ambiguous East Asian code points, which keeps deterministic cell allocation independent of font metrics. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **generation lease** (aka exact generation lease, lease-bound generation) — The exact generation and lease guard that prevents stale HOST lookups or attachments from acting on a replaced daemon or tunnel. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **grapheme** (aka extended grapheme) — A terminal-width unit built from a Unicode extended grapheme cluster whose width is decided before it is painted or copied. `docs/adr/0026-grapheme-width-and-color-emoji-fallback.md` → [terminal-core](terminal-core.md)
- **GUI action graph** (aka action graph, workflow graph) — The machine-readable map of user actions, state transitions, and recovery paths used to validate the desktop GUI against product rules. `docs/gui-action-graph.md` → [app-shell](app-shell.md)
- **HOST** (aka HOST v1, host runtime) — The authenticated host protocol that binds control and terminal access to verified owner identity, generation, and explicit grants. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host setup** (aka host provisioning, protected host setup) — The explicit local host installation path that provisions consent, identity, and service state before remote sessions become usable. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-based Dev Tunnel** (aka host-based tunnel, host tunnel) — A host-oriented Dev Tunnel flow that creates and attaches to a configured host service instead of relying on ad hoc tunnel state. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)

- **native secret store boundary** (aka secret-store boundary, credential boundary) — The explicit separation between config metadata and native platform storage, so secrets stay opaque and OS-keychain-backed. `docs/adr/0016-native-secret-store-boundary.md` → [config-secrets](config-secrets.md)

- **scrollback** (aka history, retained history) — Primary-screen logical history that survives visible-screen scroll and is bounded, reflowed, and searched as one logical content stream. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)

- **sessiond** (aka local persistence daemon, festerm-sessiond, daemon helper) — Standalone daemon that keeps one local shell alive after the app exits and exposes a local-only IPC channel. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
