# Glossary

- **alternate screen** (aka alternate buffer, ?1047) — A separate retained screen buffer with no history or reflow; leaving it restores the primary viewport state. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **application command model** (aka command model, product action model) — The shared app routing layer that converges launcher, chrome, keyboard, and inspector actions into one command path. `AGENTS.md` → [app-commands](app-commands.md)
- **cell footprint** (aka per-cell charge, compact cell charge) — The fixed in-memory cost of a terminal cell and its retained text capacity, preserved across recovery and eviction accounting. `docs/adr/0081-compact-cells-with-stable-recovery-charges.md` → [terminal-core](terminal-core.md)
- **clear scrollback** (aka Clear Scrollback, reset history) — An explicit action that discards retained primary history while keeping the current visible screen and cursor. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **DECSET** (aka private mode, mode select) — VT private-mode selector for features like mouse tracking, keypad mode, and cursor/reporting state. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **Direct2D** (aka Direct2D composition, D2D) — The optional Windows compositor path that rasterizes terminal output through native Direct2D when the adapter is eligible. `validation/direct2d/README.md` → [terminal-ui](terminal-ui.md)
- **East Asian width** (aka ambiguous width, wide-width policy) — Unicode width policy for ambiguous East Asian code points, defaulting to one-cell behavior unless configured otherwise. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **enrolled HOST** (aka enrolled-owner HOST, protected HOST) — A host identity that has passed local owner enrollment and is admitted under the current protected policy and generation. `docs/dev-tunnels-experiment.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **grapheme** (aka extended grapheme, grapheme cluster) — A segmented Unicode cluster stored in leading and continuation cells so width and erase operations stay atomic. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **GUI action graph** (aka action graph, GUI graph) — The traversable map of user interactions and recovery states that links UI edges, validation, and native evidence. `docs/gui-action-graph.md` → [app-shell](app-shell.md)
- **HOST** (aka HOST v1, host-based tunnel) — A protected host contract that ties session authority, trust, and tunnel state to explicit owner admission and host identity. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host review** (aka foreground host review, host inventory, host review/inventory) — The explicit approval flow that reviews host metadata, account state, and protected-owner consent before a connection is admitted. `docs/ui-state-narrative.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-based Dev Tunnel** (aka HOST tunnel, Dev Tunnel relay) — A tunnel flow that is rooted in explicit host identity, account binding, and reviewed owner admission rather than a bare bearer auth. `docs/dev-tunnels-experiment.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-key trust** (aka known-host trust, persistent host-key trust) — The explicit SSH host verification and persistence policy that refuses changed or unknown fingerprints without review. `README.md` → [ssh-sftp](ssh-sftp.md)
- **Job Object** (aka KILL_ON_JOB_CLOSE, breakaway job) — A Windows job that can force entire child trees to terminate when the owning app exits, unless explicitly broken away. `docs/adr/0025-native-local-session-persistence-daemon.md` → [desktop-platform](desktop-platform.md)
- **native vault** (aka protected vault, owner-store) — The OS-backed store that keeps enrolled-owner state, opaque references, and revision-checked secret metadata behind native boundaries. `docs/host-protocol.md` → [config-secrets](config-secrets.md)
- **OSC 7 working directory** (aka OSC 7, working directory) — A terminal working-directory report that stays untrusted unless it is verified or supplied by a trusted app-owned session. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **OSC 8 hyperlink** (aka OSC 8, link metadata) — A terminal hyperlink target that is normalized and validated before the app may open it from terminal content. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **owner proof** (aka SSH owner proof, enrolled-owner proof) — A cryptographic proof that binds a live SSH channel and current host policy to the exact local owner and installation. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **owner receipt** (aka protected owner receipt, foreground owner receipt) — An app-local, protected consent record that captures the current host approval and is checked before creating or opening a host session. `crates/festerm-tunnel-bridge/src/host_client/approvals.rs` → [config-secrets](config-secrets.md)
- **profile hosting** (aka installed hosting, tunnel profile) — A host tunnel or shell bound to a saved profile session so the host can resume or recreate the approved profile. `docs/application-command-model.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **query reply** (aka DECRQSS reply, DSR reply) — A terminal response to a recognized query such as cursor position, title, or color, sanitized before it is sent downstream. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **query reply socket** (aka private query reply socket, reply socket) — A private socket used for query responses and terminal-state replies, kept separate from ordinary app or daemon traffic. `docs/adr/0025-native-local-session-persistence-daemon.md` → [terminal-core](terminal-core.md)
- **recovery mirror** (aka backend-owned terminal, daemon recovery mirror) — The intentionally backend-owned terminal state that answers detached-shell queries and publishes ordered recovery snapshots. `AGENTS.md` → [sessions](sessions.md)
- **scrollback** (aka retained history, history viewport) — Primary-screen history kept as ordered logical lines with a configured byte budget and eviction policy. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **scrollback limit** (aka retention budget, history budget) — The configured byte cap for retained primary history; it bounds logical lines and eviction without changing visible-screen geometry. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **sessiond** (aka festerm-sessiond, local persistence daemon) — Detached local shell manager that owns a PTY/ConPTY and exposes attach, list, and kill for durable sessions. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **SFTP** (aka GUI SFTP, text-mode SFTP) — A file-transfer surface that opens as a separate app lifecycle beside SSH sessions, using verified host and profile context. `docs/sftp-ui-design.md` → [ssh-sftp](ssh-sftp.md)
- **source snapshot** (aka workflow snapshot, immutable bundle) — A frozen, validated workflow file loaded only through explicit native user selection and never treated as grant authority. `crates/festerm-automation-workflow/src/intake.rs` → [automation](automation.md)
- **terminal capability advertisement** (aka terminfo entry, TERM capability) — The advertised terminal feature set and behavior description packaged in the terminal environment and versioned compatibility checks. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **terminal output is untrusted** (aka untrusted output, unsafe terminal output) — The parser must never turn terminal output into implicit input, clipboard disclosure, network action, or process execution. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **terminal replies owned by backend** (aka backend replies, terminal_replies_owned_by_backend) — A backend-owned terminal discards stale reply traffic so detached sessions never fabricate answers without a live GUI owner. `AGENTS.md` → [terminal-core](terminal-core.md)
- **traceability** (aka validation traceability, evidence mapping) — The machine-checked retention of requirement, ADR, scenario, and test links used to prove behavior and guide review. `AGENTS.md` → [app-commands](app-commands.md)
- **trusted ConPTY runtime** (aka verified ConPTY, sidecar runtime) — A hash-verified Windows pseudoconsole sidecar loaded from the canonical runtime path before the first PTY is opened. `docs/adr/0011-trusted-windows-conpty-runtime-selection.md` → [desktop-platform](desktop-platform.md)
- **Validation-Impact** (aka validation impact, Validation Impact) — A commit trailer that names the UI or ADR edges affected and ties changes to the review graph and acceptance evidence. `AGENTS.md` → [app-commands](app-commands.md)
- **verified host** (aka verified SSH host, host pin) — A host identity whose SSH key or tunnel identity has been explicitly authenticated and locked to the active session or profile. `docs/host-protocol.md` → [ssh-sftp](ssh-sftp.md)
- **WARP** (aka Windows WARP, software rasterizer) — The Windows software rendering path used in the Direct2D eligibility tests and fallback comparisons. `validation/direct2d/README.md` → [terminal-ui](terminal-ui.md)
- **workflow bundle** (aka automation bundle, SourceSnapshot) — A frozen, validated bundle of workflow manifest, modules, and parameter schema that is approved before execution. `docs/automation-design.md` → [automation](automation.md)
