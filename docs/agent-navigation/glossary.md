# Glossary

- **admission epoch** (aka automation epoch, epoch) — Non-reusable generation value that marks a backend attachment's current running state before disclosure or input. `crates/festerm-admission/src/lib.rs::AutomationEpoch` → [automation](automation.md)
- **automation admission lock** (aka admission lock, automation lock) — Process-wide serialization boundary that prevents races while backend transitions and automation disclosures are checked. `crates/festerm-admission/src/lib.rs::automation_admission_lock` → [automation](automation.md)
- **bounded ingest** (aka ingest budget, backpressure ingest) — Per-window shared 4 ms terminal-ingest budget that keeps parsing work bounded across busy sessions. `docs/adr/0079-global-terminal-ingest-budget.md` → [terminal-core](terminal-core.md)
- **cell footprint** (aka history charge, cell charge) — Per-cell memory and capacity charge used to bound history retention, reflow, and recovery accounting. `docs/adr/0081-compact-cells-with-stable-recovery-charges.md` → [terminal-core](terminal-core.md)
- **controller handoff** (aka handoff, controller transfer) — Transfer of a session or operation to a new controller after generation and admission checks confirm the target is still current. `docs/automation-design.md` → [automation](automation.md)
- **daemon-owned leases** (aka owner lease, lease epoch, issuance epoch, epoch guard) — Protected daemon-issued time-bounded rights that pin a live generation and reject stale or revoked attach attempts. `docs/host-protocol.md` → [sessions](sessions.md)
- **DECSET** (aka ANSI mode, mode setting) — ANSI mode-setting control that toggles wrap, margins, mouse reporting, and other terminal behavior. `COMPATIBILITY.md` → [terminal-core](terminal-core.md)
- **Direct2D** (aka D2D, Direct2D path) — Windows Direct2D rendering path used for supported software-renderer and retained-frame painting in the desktop UI. `validation/direct2d/README.md` → [desktop-platform](desktop-platform.md)
- **generation** (aka daemon generation, attachment generation) — Exact nonzero daemon or attachment incarnation number used for attach, detach, and takeover fencing across retries. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **grapheme** (aka cluster, extended grapheme) — A terminal grapheme is the UAX 29 unit that holds combining marks, flags, emoji, and width decisions as one cell-geometry object. `docs/adr/0026-grapheme-width-and-color-emoji-fallback.md` → [terminal-core](terminal-core.md)
- **GUI action graph** (aka action graph, route graph) — Named, validated user-action model that maps UI edges to required behavior and manual or automated proofs. `docs/gui-action-graph.md` → [app-commands](app-commands.md)
- **history recovery** (aka recovery replay, recovery state) — Restore path that rehydrates the terminal from the daemon or session snapshot without replaying stale shell-side replies. `ARCHITECTURE.md` → [sessions](sessions.md)
- **HOST** (aka host protocol, host runtime) — Authenticated host runtime and transport contract for inventory, create, attach, and exact-generation session operations. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host control** (aka NativeControl, control plane) — The authenticated host-side control flow that manages daemon inventory, creation, attach, and exact-generation lifecycle checks. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-based Dev Tunnel** (aka dev tunnel host, host tunnel) — Host-oriented tunnel flow that binds a remote shell to a reviewed host/service recipe and exact daemon generation. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **Job Object** (aka KILL_ON_JOB_CLOSE, windows job) — Windows process-tree boundary that kills all assigned processes when the owning job closes. `crates/festerm-windows-job/src/lib.rs::WindowsJob` → [desktop-platform](desktop-platform.md)
- **local PTY** (aka PTY backend, ConPTY backend) — Platform-local PTY or ConPTY backend that owns the shell process and stream workers while the app keeps terminal state separate. `ARCHITECTURE.md` → [sessions](sessions.md)
- **native secret store** (aka secret store, platform secret store) — GUI-independent secret boundary that stores opaque credentials in the OS keychain and exposes no plaintext or file fallback. `docs/adr/0016-native-secret-store-boundary.md` → [config-secrets](config-secrets.md)
- **native vault** (aka platform vault, secret vault) — Operating-system-backed protected store used for owner and service credentials rather than ordinary TOML config. `README.md` → [config-secrets](config-secrets.md)
- **owner proof** (aka owner auth, proof, owner-auth, auth) — Bounded authenticated proof that the current client and host actually match the protected owner and role being used. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **profile hosting** (aka host recipe, hosting, profile recipe, recipe) — Saved host recipe metadata that describes a shell or tunnel without granting access until explicit review and consent. `docs/configuration.md` → [config-secrets](config-secrets.md)
- **recovery mirror** (aka daemon mirror, mirror) — The authoritative backend-owned terminal snapshot that receives PTY output and recovery controls while the app reattaches. `ARCHITECTURE.md` → [sessions](sessions.md)
- **recovery snapshot** (aka session snapshot, snapshot) — Length-prefixed terminal snapshot that a reattaching client adopts before live output resumes from the daemon. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **remote daemon** (aka persistent daemon, local daemon) — Detached background shell process that preserves a live terminal across GUI restarts and exposes a local IPC interface. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **scrollback** (aka history, logical scrollback) — Bounded in-memory terminal history retained for prior screen rows and viewport navigation, excluding alternate-screen output. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **scrollback limit** (aka history limit, history cap) — Configured maximum retained logical history, enforced by the terminal and session recovery logic before eviction or snapshotting. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **session attach** (aka attach, adopt) — Client-side adoption of a running session after the backend verifies its snapshot, generation, and ownership before live output resumes. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **sessiond** (aka daemon, local persistence daemon) — Opt-in standalone daemon that owns one detached local PTY and its recovery snapshot for reconnecting tabs. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **sessiond attach** (aka attach to daemon, daemon attach) — Protocol-v2 attach path that reads the recovery snapshot and then adopts the daemon's live terminal state before processing more output. `ARCHITECTURE.md` → [sessions](sessions.md)
- **synthetic backend** (aka synthetic peer, test backend) — A test-only automation backend used to exercise protocol dispatch and approval flow without live native qualification. `docs/automation-design.md` → [automation](automation.md)
- **terminal reply** (aka reply, backend reply) — Terminal protocol reply emitted by the backend while parsing output, whose ownership is explicitly separated from frontend mutation. `crates/festerm-session/src/lib.rs::SessionEvent` → [sessions](sessions.md)
- **terminal_replies_owned_by_backend** (aka backend-owned replies, reply ownership) — Flag showing whether the backend, not the frontend terminal, answers terminal protocol replies created while parsing output. `crates/festerm-session/src/lib.rs::terminal_replies_owned_by_backend` → [sessions](sessions.md)
- **Validation-Impact** (aka validation impact, impact trailer) — Commit trailer naming the GUI or ADR edges affected by a change so traceability stays tied to implementation edits. `docs/development-governance.md` → [automation](automation.md)
- **WARP** (aka Microsoft WARP, WARP renderer) — Windows software rasterizer path used for deterministic CPU-side rendering and performance evidence on supported hosts. `validation/windows-warp/README.md` → [desktop-platform](desktop-platform.md)
- **workflow bundle** (aka automation bundle, bundle) — Frozen automation package with manifest, modules, and parameter schema, approved before execution. `docs/automation-design.md` → [automation](automation.md)
