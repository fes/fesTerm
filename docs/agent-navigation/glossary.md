- **attachment takeover** (aka steal-on-reconnect, single-writer takeover) — Protocol rule that a new attach replaces the previous live client when a daemon already has one attached. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **bounded ingest** (aka ingest budget, terminal input budget) — Per-window shared limit on terminal ingestion that keeps GUI updates responsive while preserving input ordering. `docs/adr/0079-global-terminal-ingest-budget.md` → [terminal-core](terminal-core.md)
- **bounded logical scrollback** (aka retained history, logical history) — History stored as ordered logical lines with strict byte accounting and stable anchors across resize. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **cell footprint** (aka compact cell layout, cell memory cost) — The in-memory size of a terminal cell and its history charge, kept conservative for recovery compatibility. `docs/adr/0081-compact-cells-with-stable-recovery-charges.md` → [terminal-core](terminal-core.md)
- **controller handoff** (aka handoff controller, controller transfer) — The explicit transfer of control from one reviewed controller instance to another under a valid grant and epoch. `docs/automation-design.md` → [automation](automation.md)
- **DECSET** (aka ANSI mode set, XT mode) — Mode-setting escape sequence that toggles terminal behavior such as reverse wraparound and margin rules. `docs/adr/0037-reverse-wraparound-bounds.md` → [terminal-core](terminal-core.md)
- **Dev Tunnel bridge** (aka bridge relay, remote bridge) — Separate remote process that terminates a Dev Tunnel and speaks to the local daemon behind protected local IPC. `docs/adr/0053-separate-dev-tunnels-session-bridge.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **Direct2D** (aka Windows Direct2D, D2D) — Windows native composition path used for eligible terminal frames on supported x64 WARP targets. `docs/adr/0039-opt-in-direct2d-terminal-composition.md` → [terminal-ui](terminal-ui.md)
- **East Asian width** (aka double-width policy, wide-cell width) — The deterministic width model used to decide when a grapheme occupies one or two terminal cells. `docs/adr/0026-grapheme-width-and-color-emoji-fallback.md` → [terminal-core](terminal-core.md)
- **enrolled HOST** (aka verified host, host enrollment) — Legacy/manual host enrollment with protected owner evidence; distinct from ordinary provider-authorized account access. `docs/dev-tunnels-experiment.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **fingerprint-first SSH auth** (aka SSH fingerprint ordering, auth-before-password) — SSH flow that verifies host identity before requesting a password or other interactive credential. `docs/adr/0019-fingerprint-first-ssh-authentication-ordering.md` → [ssh-sftp](ssh-sftp.md)
- **generation** (aka daemon generation, session generation) — An incarnation identifier distinguishing one daemon and fencing stale attachment across reconnects. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **grapheme** (aka cluster, extended grapheme) — A user-perceived Unicode cluster that keeps combining marks and emoji sequences together for width and layout. `docs/adr/0026-grapheme-width-and-color-emoji-fallback.md` → [terminal-core](terminal-core.md)
- **GUI action graph** (aka action graph, GUI workflow graph) — The traversable workflow map of user actions, states, errors, and recovery paths used in GUI validation. `docs/gui-action-graph.md` → [app-shell](app-shell.md)
- **history recovery** (aka recoverable history, recovery history) — Recovery path that restores retained terminal history and parser state after a session detaches or reattaches. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **HOST** (aka host service, host-based tunnel) — A configured host endpoint that lists authorized sessions and can create or attach to remote shells under host policy. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-based Dev Tunnel** (aka HOST tunnel, host tunnel) — The owner-selected host-first Dev Tunnel flow that exposes configured host endpoints and sessions through host policy. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-key trust** (aka known host trust, known_hosts trust) — Persisted SSH host-key fingerprint trust that allows reconnects without re-prompting for an already accepted host. `docs/adr/0020-persistent-host-key-trust.md` → [ssh-sftp](ssh-sftp.md)
- **Job Object** (aka Windows Job Object, job object) — Windows process-lifetime container; the PTY owner uses kill-on-close for its shell tree. `docs/adr/0025-native-local-session-persistence-daemon.md` → [desktop-platform](desktop-platform.md)
- **local-first sync metadata** (aka metadata-only sync, local-first metadata) — Local-first operation model that syncs only non-secret metadata and avoids moving secrets into shared metadata flows. `docs/adr/0003-local-first-sync-metadata-not-secrets.md` → [config-secrets](config-secrets.md)
- **native secret store boundary** (aka OS secret boundary, secret-store boundary) — The guarded native OS-keystore layer that keeps protected secrets outside ordinary TOML and synchronized metadata. `docs/adr/0016-native-secret-store-boundary.md` → [config-secrets](config-secrets.md)
- **native vault** (aka OS keychain, secret store) — The OS-native protected secret store used for credential references that must stay outside ordinary config files. `docs/adr/0016-native-secret-store-boundary.md` → [config-secrets](config-secrets.md)
- **owner binding** (aka verified owner binding, host owner binding) — Protected host key and action binding verified against the same owner context and installation identity. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **owner proof** (aka channel owner proof, verified owner proof) — Cryptographic proof that a live SSH channel and host binding belong to the same verified owner context. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **persistent host-key trust** (aka saved host key, remembered trust) — Saved host-fingerprint record used to silently accept a matching key on later SSH connections. `docs/adr/0020-persistent-host-key-trust.md` → [ssh-sftp](ssh-sftp.md)
- **profile hosting** (aka installed-host profile, hosted local profile) — Opt-in local profile hosting that starts a detached daemon and exposes it through the host service model. `docs/adr/0072-installed-profile-tunnel-hosting.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **recovery mirror** (aka authoritative mirror, daemon mirror) — A daemon-owned terminal snapshot that preserves parser state for reattach recovery without replaying stale replies. `crates/festerm-sessiond/src/main.rs::mirror_terminal_output` → [sessions](sessions.md)
- **recovery snapshot** (aka attach snapshot, daemon snapshot) — A bounded serialized terminal state sent before live output so reattach restores the same screen/history state. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **scrollback** (aka history buffer, terminal history) — Retained primary-screen history with logical lines, cell ownership, and a strict byte budget. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **separate profiles and workspaces** (aka profile/workspace split, split profiles/workspaces) — Design that keeps logical profiles and workspaces distinct so configuration and runtime state do not collapse together. `docs/adr/0002-separate-profiles-and-workspaces.md` → [config-secrets](config-secrets.md)
- **sessiond** (aka session daemon, local persistence daemon) — Standalone local persistence daemon that owns one PTY/ConPTY session and exposes attach/list/kill operations. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
