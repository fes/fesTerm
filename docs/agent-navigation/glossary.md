- **alternate screen** (aka alt screen, alternate buffer) — The separate terminal buffer for application modes that suspends and restores primary-screen history and viewport state. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **application command** (aka app intent, command model) — A single semantic action whose behavior is shared across launcher, keyboard, menu, and automation entry points. `docs/application-command-model.md` → [app-commands](app-commands.md)
- **automation broker** (aka broker, automation kernel) — The application-owned automation boundary that validates grants, routes requests, and prevents direct backend access. `docs/automation-design.md` → [automation](automation.md)
- **bounded logical scrollback** (aka logical history, history retention) — Ordered primary-screen history with a strict byte budget, stable logical positions, and no alternate-screen retention. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **command route** (aka keyboard route, app route) — The routing path that resolves a UI gesture or input to one typed application action and then to the proper session target. `docs/application-command-model.md` → [app-commands](app-commands.md)
- **Direct2D** (aka native D2D, D2D composition) — The Windows native path that reuses the wgpu surface while painting terminal content through Direct2D when supported. `docs/adr/0039-opt-in-direct2d-terminal-composition.md` → [terminal-ui](terminal-ui.md)
- **emoji presentation** (aka color emoji, monochrome emoji) — The renderer policy that chooses deterministic color or monochrome emoji output without changing terminal cell geometry. `docs/adr/0026-grapheme-width-and-color-emoji-fallback.md` → [terminal-core](terminal-core.md)
- **generation** (aka session generation, daemon generation) — A nonzero, monotonic session incarnation number that distinguishes live shell generations and prevents stale reattachment. `crates/festerm-host-protocol/src/identity.rs::GenerationId` → [sessions](sessions.md)
- **grapheme cluster** (aka extended grapheme, grapheme) — A sequence of Unicode scalars treated as one cell-width unit, including emoji modifiers and ZWJ sequences. `docs/adr/0026-grapheme-width-and-color-emoji-fallback.md` → [terminal-core](terminal-core.md)
- **GUI action graph** (aka action graph, UI action graph) — The explicit command-flow model that keeps UI gestures, keyboard input, and menus routed through one product action. `docs/gui-action-graph.md` → [app-commands](app-commands.md)
- **history anchor** (aka viewport anchor, stable anchor) — A logical position used for viewport follow state, selection, and search that survives row reflow and trimming. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **HOST** (aka HOST v1, host protocol) — The host-side authenticated session protocol that separates host identity, issuance epochs, and terminal/control streams. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host identity** (aka stable host id, host UUID) — The canonical host identifier that distinguishes a configured service instance from hostname or profile labels. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host service** (aka configured host, host runtime) — The configured local host service that owns protected identity, inventory, and the session creation boundary. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-based Dev Tunnel** (aka host tunnel, HOST tunnel) — A host-oriented Dev Tunnel design where a configured service exposes inventory and remote session creation without relying on legacy tunnel-only flow…. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-key trust** (aka known-host trust, SSH host trust) — The verified SSH host-key policy that gates remote connections and establishes the trusted identity before session use. `docs/configuration.md` → [ssh-sftp](ssh-sftp.md)
- **issuance epoch** (aka issue epoch, creation epoch) — A monotonic host issuance value that fences new Ensure/Create actions and rejects stale or replayed operations. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **Job Object** (aka windows job, kill-on-close job) — The Windows process group that enforces process-tree shutdown and prevents a daemon from being torn down with fesTerm. `crates/festerm-pty/src/lib.rs` → [desktop-platform](desktop-platform.md)
- **local PTY** (aka local shell PTY, ConPTY) — The local terminal session backed by a PTY or ConPTY that produces the session byte stream before persistence or remote routing. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **native vault** (aka vault, native secret store) — The OS-native protected store used for owner keys, trust records, and protected host-local consent material. `docs/adr/0016-native-secret-store-boundary.md` → [config-secrets](config-secrets.md)
- **owner binding** (aka verified owner binding, host owner binding) — The protected identity that ties a host-local key, host fingerprint, and session action to one exact verified owner context. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **owner proof** (aka enrolled owner proof, HOST owner proof) — The challenge-and-signature flow that proves the same host-key-pinned channel is authorized to act for the host owner. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **profile hosting** (aka hosted profile, host recipe hosting) — A host-side or profile-based workflow that publishes and reuses remote session recipes without turning them into grants. `docs/configuration.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **public host recipe** (aka host recipe, portable recipe) — An offline metadata document describing a host target and launch behavior without granting trust or execution authority. `docs/configuration.md` → [config-secrets](config-secrets.md)
- **recovery mirror** (aka daemon mirror, authoritative mirror) — The daemon-owned terminal state that preserves parser state, screen history, and mode data for safe reattach. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [terminal-core](terminal-core.md)
- **recovery snapshot** (aka snapshot prelude, attach snapshot, recovery prelude, attach prelude) — A bounded serialized terminal state sent before live output so a reattached client resumes the same terminal state. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [terminal-core](terminal-core.md)
- **remote observation** (aka read-only observation, observation provider) — A bounded read-only access model that exposes terminal state without granting filesystem, control, or Shell execution authority. `docs/remote-observation-protocol.md` → [automation](automation.md)
- **scrollback budget** (aka history budget, retained history) — The configured maximum binary bytes retained for primary-screen history, with eviction and accounting rules. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **secret boundary** (aka secret store boundary, native secret boundary) — The strict layer that keeps secret material out of portable config, workspaces, and app state while storing it in native protection. `docs/adr/0016-native-secret-store-boundary.md` → [config-secrets](config-secrets.md)
- **session ownership** (aka window ownership, tab ownership) — The project rule that the window, workspace, tab, and session each own distinct lifetimes and state transitions. `docs/adr/0014-window-workspace-tab-session-ownership.md` → [app-shell](app-shell.md)
- **sessiond** (aka session daemon, sessiond daemon) — A standalone local daemon that keeps a shell PTY alive across app exits and reattaches to it with recovery state. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **SFTP** (aka remote file manager, SFTP surface) — The file-transfer surface that reuses SSH trust and exposes live or saved remote file browsing and transfer operations. `docs/sftp-ui-design.md` → [ssh-sftp](ssh-sftp.md)
- **steal-on-reconnect** (aka attach takeover, single-live-client) — The daemon policy where the newest attach forcibly takes over an already-attached session instead of multiplexing clients. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **terminal snapshot schema** (aka snapshot schema, recovery schema) — The versioned serialized terminal format used to validate and adopt daemon-owned recovery state across reattach. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [terminal-core](terminal-core.md)
- **WARP** (aka Windows WARP, WARP rasterizer) — The Windows software rasterizer path used by the supported Direct2D terminal composition default when adapters match. `validation/windows-warp/README.md` → [terminal-ui](terminal-ui.md)
- **workflow bundle** (aka JS bundle, automation bundle) — The user-selected packaged workflow or script definition that the broker admits under bounded automation rules. `docs/automation-design.md` → [automation](automation.md)
