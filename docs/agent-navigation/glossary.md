- **admission epoch** (aka freshness epoch) — A process-wide freshness token that invalidates stale automation attachments and disclosures. `crates/festerm-admission/src/lib.rs::AutomationEpoch` → [automation](automation.md)
- **alternate screen** (aka alternate buffer) — The retained alternate terminal buffer that suspends primary history and restores it on return. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **anchored viewport** (aka history anchor) — A viewport state pinned to a retained logical position instead of following new output automatically. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **bounded logical scrollback** (aka logical history) — History stored as ordered logical lines with explicit per-session charging and eviction limits. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **cell geometry** (aka cell grid) — The terminal core owns cell coordinates while rendering owns fonts, shaping, and pixels. `docs/adr/0012-cell-geometry-owns-ligature-and-fallback-mapping.md` → [terminal-core](terminal-core.md)
- **daemon-owned leases** (aka owning lease) — Session lifetime and takeover are enforced by daemon-owned lease epochs and expiry rather than client-side guesses. `docs/configuration.md` → [sessions](sessions.md)
- **DECSET** (aka private mode) — A DEC private-mode set/reset control that flips terminal behavior such as mouse reporting or reverse wrap. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **Direct2D** (aka D2D) — The Windows native composition path selected for eligible DX12 software-adapter terminals. `app/festerm/src/direct2d.rs` → [desktop-platform](desktop-platform.md)
- **East Asian width** (aka ambiguous width) — Use the pinned width table and non-CJK policy so ambiguous East Asian code points occupy the expected cell width. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **enrolled HOST** (aka owner enrollment) — An explicitly enrolled per-host owner key used with host-local protected consent and native secret storage. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **exact generation** (aka generation pin) — An exact live session or daemon generation that a client must match before attaching or resuming. `docs/configuration.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **generation** (aka attachment generation, live generation) — A monotonic backend generation that pins live session identity and refuses stale or replaced attachments. `crates/festerm-admission/src/lib.rs::AutomationEpoch` → [sessions](sessions.md)
- **grapheme** (aka grapheme cluster) — A user-perceived character cluster segmented before cell allocation and width decisions. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **HOST** (aka host service, host daemon) — A configured host service instance with stable identity, protected owner proof, and session lifecycle. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-based Dev Tunnel** (aka host tunnel) — A tunnel that reaches a configured host service rather than a generic public relay endpoint. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-key trust** (aka known hosts, known_hosts) — A stored SSH host fingerprint policy that accepts matching keys without prompting and rejects changed keys. `docs/configuration.md` → [ssh-sftp](ssh-sftp.md)
- **Job Object** (aka kill-on-close job) — A Windows Job Object that terminates the child process tree when the owning session closes. `crates/festerm-windows-job/src/lib.rs::WindowsJob` → [desktop-platform](desktop-platform.md)
- **local PTY** (aka native PTY) — The local pseudoterminal used by a native session and bounded by OS-specific PTY or ConPTY semantics. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **local session persistence daemon** (aka native persistence daemon) — The local daemon model that owns a detached PTY/ConPTY and provides bounded recovery state to clients. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **native vault** (aka secret store) — The platform native credential store used for protected owner seeds, keys, and opaque references. `docs/host-protocol.md` → [config-secrets](config-secrets.md)
- **owner binding** (aka host-owner binding) — The exact host identity, owner key, receipt, and epoch bound to an authorized HOST operation. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **owner proof** (aka owner signing) — The explicit enrolled owner signing key that proves a configured host owner, not an asserted account identity. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **owner signing key** (aka OwnerSigningKey) — A per-host Ed25519 signing key stored in native protected storage and validated before HOST access is granted. `docs/host-protocol.md::OwnerSigningKey` → [tunnels-enterprise](tunnels-enterprise.md)
- **persistent daemon** (aka sessiond daemon) — A detached helper that keeps a local shell alive independently of the GUI process and restores exact state on reattach. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **primary screen history** (aka retained history) — Primary-screen logical lines kept in order with explicit identity, bounds, and resize reflow semantics. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **profile hosting** (aka installed hosting) — The host-side profile model that binds a tunnel to an installed profile and remote session lifecycle. `docs/application-command-model.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **public metadata** (aka portable metadata) — Non-secret host, recipe, or profile data that may be exported without exposing credentials or protected receipts. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **recovery mirror** (aka authoritative mirror) — The daemon-owned terminal model that preserves parser state, scrollback, and modes across reattach. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **recovery snapshot** (aka snapshot prelude) — A length-prefixed serialized terminal state sent before live output so reattach restores exact parser and screen state. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **scrollback** (aka history) — Retained primary-screen output that survives terminal movement and is bounded by configured budget. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **scrollback limit** (aka history budget) — The configured byte budget that bounds retained primary-screen history and enforces eviction. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **session lifecycle** (aka lifecycle contract) — The runtime contract for startup, attach, detach, reconnect, shutdown, and recovery of a session. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **sessiond** (aka session daemon) — A standalone per-session local daemon that keeps a PTY/ConPTY shell alive across frontend exits and reattach. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **SFTP** (aka SSH file transfer) — A first-class SSH subsystem session that reuses the transport, trust, and terminal surface of SSH sessions. `docs/adr/0028-text-mode-sftp-session-tabs-via-russh-sftp.md` → [ssh-sftp](ssh-sftp.md)
- **terminal parser** (aka ANSI parser) — The state machine that interprets C0/C1 bytes, CSI sequences, OSC payloads, and malformed escapes. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **terminal query reply** (aka DSR reply) — A terminal protocol reply such as cursor or title status issued in response to a recognized device-query request. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **terminal_replies_owned_by_backend** (aka backend-owned replies) — Whether the backend answers terminal protocol replies instead of the frontend terminal clone. `crates/festerm-session/src/lib.rs::terminal_replies_owned_by_backend` → [sessions](sessions.md)
- **WARP** (aka Windows WARP) — The Windows software rasterizer used for eligible Direct2D terminal rendering and proof checks. `validation/windows-warp/README.md` → [desktop-platform](desktop-platform.md)
