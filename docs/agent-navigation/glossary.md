- **DECSET** (aka mode set, terminal mode) — A terminal mode-set escape that toggles behavior such as mouse tracking, margins, or reverse wrap. `crates/festerm-core/src/modes.rs::TerminalModes` → [terminal-core](terminal-core.md)
- **Direct2D** (aka DX12 CPU path, direct paint) — The Windows DX12 CPU direct-paint path used only on supported x64 terminals with compatible targets. `docs/configuration.md` → [terminal-ui](terminal-ui.md)
- **East Asian width** (aka wide-cell width, ambiguous width) — The Unicode width policy that assigns one or two terminal cells to ambiguous and wide characters. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **enrolled HOST** (aka host enrollment, approved HOST) — A HOST instance whose owner signing key and protected host policy have been locally enrolled and approved. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **generation** (aka daemon generation, session generation) — A monotonic session or daemon identity used to pin reattach, replacement, and lease decisions. `docs/host-protocol.md` → [sessions](sessions.md)
- **grapheme** (aka grapheme cluster, cluster) — An extended Unicode cluster treated as one terminal unit for width, selection, and cursor geometry. `crates/festerm-core/src/unicode.rs::grapheme_width` → [terminal-core](terminal-core.md)
- **GUI action graph** (aka workflow graph, state graph) — The stable UI workflow map of state transitions, recoveries, and validation edges used by tests and reviews. `docs/gui-action-graph.md` → [app-commands](app-commands.md)
- **HOST** (aka host service, host endpoint) — The fesTerm host protocol and service model for a verified remote access session, not a generic hostname. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host identity** (aka stable host ID, host UUID) — The stable host UUID and fingerprint pairing used to pin trust and route permissions to one host instance. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host recipe metadata** (aka public recipe, recipe metadata) — Description-only host recipe data used for review and import without creating a host grant. `docs/configuration.md` → [config-secrets](config-secrets.md)
- **host-based Dev Tunnel** (aka HOST tunnel, dev tunnel host) — A host-oriented tunnel workflow that creates and attaches to persistent remote sessions after explicit owner proof. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-key trust** (aka known-host trust, host trust) — Persistent SSH trust that remembers a host fingerprint and flags changed keys for explicit review. `docs/adr/0020-persistent-host-key-trust.md` → [ssh-sftp](ssh-sftp.md)
- **Job Object** (aka Windows job, process job) — A Windows process-group boundary that terminates child shells when the owning app exits unless detached. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **local PTY** (aka native PTY, PTY) — A native local pseudo-terminal instance that runs a shell under the user’s OS and exposes terminal I/O. `crates/festerm-pty/src/lib.rs::LocalPtySession` → [sessions](sessions.md)
- **native secret store** (aka secret store boundary, OS secret store) — The GUI-independent secret boundary that stores only opaque references in the OS keychain. `docs/adr/0016-native-secret-store-boundary.md` → [config-secrets](config-secrets.md)
- **native vault** (aka OS keychain, secret vault) — OS keychain-backed secret storage that keeps opaque credential references outside config and sync metadata. `docs/adr/0016-native-secret-store-boundary.md` → [config-secrets](config-secrets.md)
- **owner enrollment** (aka owner key setup, owner setup) — The local protected setup that creates and stores a per-host owner signing key and policy. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **owner proof** (aka owner auth, proof) — A signed, host-bound enrollment proof that shows the device and owner are authorized for HOST access. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **owner signing key** (aka enrollment key, host key) — An Ed25519 key stored in the native vault and used to prove host ownership on a pinned channel. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **persistent session** (aka durable session, surviving session) — A durable local or host session that stays alive after the app closes and can be reattached. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **profile hosting** (aka hosted profile, remote profile) — A saved profile or recipe that can be offered as a persistent hosted session or remote access target. `docs/application-command-model.md` → [config-secrets](config-secrets.md)
- **recovery mirror** (aka output mirror, daemon mirror) — A daemon-owned mirror that drains backend terminal replies while the frontend is detached or reattaching. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **recovery snapshot** (aka reattach snapshot, snapshot) — A serialized terminal state sent at attach time so a reattached client can resume without replaying raw output. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **remote observation protocol** (aka read-only observation, observation protocol) — A read-only transport that exposes terminal metadata without granting shell or file controls. `docs/remote-observation-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **scrollback** (aka history buffer, retained history) — Retained terminal history kept as bounded logical lines with stable anchors across resize and reflow. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **session discovery** (aka inventory discovery, session inventory) — The inventory API that enumerates live daemon sessions, versions, and compatibility status. `crates/festerm-sessiond/src/lib.rs::SessionDiscovery` → [sessions](sessions.md)
- **session grant** (aka logical grant, access grant) — Protected authorization metadata that binds a logical session to an owner, generation, and remote-access state. `crates/festerm-host-protocol/src/resources.rs::SessionGrant` → [tunnels-enterprise](tunnels-enterprise.md)
- **session lifecycle** (aka SessionLifecycle, lifecycle) — The ordered states and events for creating, attaching, reattaching, and shutting down a terminal session. `crates/festerm-session/src/lib.rs::SessionLifecycle` → [sessions](sessions.md)
- **session registry** (aka daemon registry, live registry) — The on-disk registry that records live daemon sessions, their socket paths, and stale-entry pruning. `crates/festerm-sessiond/src/lib.rs::SessionRegistry` → [sessions](sessions.md)
- **sessiond** (aka local persistence daemon, daemon) — A standalone local persistence daemon that owns one PTY, keeps it alive beyond the GUI, and exposes attach/list/kill control. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **SFTP** (aka GUI SFTP, file transfer) — A secure file-transfer session built over authenticated SSH transport and remote file operations. `crates/festerm-ssh/src/sftp.rs::SftpSession` → [ssh-sftp](ssh-sftp.md)

- **terminal_replies_owned_by_backend** (aka backend-owned replies, backend replies) — A backend capability that suppresses duplicate terminal replies while the daemon owns the recovery mirror. `crates/festerm-session/src/lib.rs::Session` → [sessions](sessions.md)
