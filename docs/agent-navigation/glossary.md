- **application command** (aka AppCommand) — Single semantic action that routes launcher, keyboard, menu, and settings invocation to one application path. `docs/application-command-model.md` → [app-commands](app-commands.md)
- **automation authority kernel** (aka authority kernel) — Pure application state enforcing grant, quota, and run boundaries without enabling unqualified MCP or JavaScript. `crates/festerm-automation/README.md` → [automation](automation.md)
- **controller handoff** (aka input handoff, ownership handoff) — Serialized transfer of focus and input ownership between controller, session, and backend components. `app/festerm/src/session_controller.rs` → [automation](automation.md)
- **Direct2D** (aka D3D11-on-12) — Native Windows terminal composition path that keeps app-owned terminal semantics while reusing the existing wgpu surface. `docs/adr/0039-opt-in-direct2d-terminal-composition.md` → [desktop-platform](desktop-platform.md)
- **East Asian width** (aka unicode width) — Width policy assigning narrow or wide cells to terminal graphemes to keep geometry deterministic. `docs/adr/0026-grapheme-width-and-color-emoji-fallback.md` → [terminal-core](terminal-core.md)
- **generation** (aka attachment generation, daemon generation) — Monotonic per-backend identity that invalidates stale attachments, observations, and reconnects. `crates/festerm-admission/src/lib.rs::AutomationEpoch` → [sessions](sessions.md)
- **grapheme** (aka extended grapheme) — Unicode cluster treated as one terminal unit with deterministic cell width and fallback behavior. `docs/adr/0026-grapheme-width-and-color-emoji-fallback.md` → [terminal-core](terminal-core.md)
- **GUI action graph** (aka action graph) — Normative map of user-visible GUI states, transitions, and recovery edges that must stay traceable to tests. `docs/gui-action-graph.md` → [app-commands](app-commands.md)
- **history recovery** (aka reattach recovery, snapshot recovery) — Rebuilding the same terminal state after detach or reconnect from an authoritative daemon snapshot. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [terminal-core](terminal-core.md)
- **HOST** (aka host protocol, host runtime, host_runtime) — Authenticated host protocol for protected remote session creation, inventory, and terminal routing. `docs/host-protocol.md` → [ssh-sftp](ssh-sftp.md)
- **host key approval** (aka verified host) — Explicit trust check that the exact SSH host key matches the approved installation before a connection opens. `crates/festerm-tunnel-bridge/src/host_client.rs` → [ssh-sftp](ssh-sftp.md)
- **host-based Dev Tunnel** (aka HOST tunnel, dev tunnel host) — Explicit account-scoped host workflow that creates or attaches a remote shell through a verified tunnel. `docs/ui-state-narrative.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **Job Object** (aka Windows Job Object) — Windows process-tree boundary that terminates or isolates child processes during shutdown and PTY lifecycle tests. `crates/festerm-windows-job/src/lib.rs` → [desktop-platform](desktop-platform.md)
- **native smoke** (aka native PTY smoke) — End-to-end production PTY/session tests that validate real resize, output continuity, and bounded shutdown outside fixtures. `docs/native-smoke-policy.md` → [desktop-platform](desktop-platform.md)
- **native SSH backend** (aka russh backend, native SSH transport) — Native SSH implementation that authenticates with host keys and the approved owner proof before session creation. `docs/adr/0013-russh-native-ssh-transport.md` → [ssh-sftp](ssh-sftp.md)
- **native vault** (aka secret store, native keyring) — Platform keychain boundary storing only opaque secret references and no plaintext config data. `docs/host-protocol.md` → [config-secrets](config-secrets.md)
- **owner approval** (aka foreground owner approval, host-key approval) — Explicit local consent step before a host key or owner key can authorize a protected connection. `crates/festerm-tunnel-bridge/src/host_client.rs` → [ssh-sftp](ssh-sftp.md)
- **owner enrollment** (aka protected enrollment) — Protected local setup storing an owner signing key and policy for a specific host and installation. `README.md` → [config-secrets](config-secrets.md)
- **owner proof** (aka channel owner proof, owner-auth, owner authentication, owner auth) — Cryptographic proof that the live SSH channel and host binding belong to the same approved owner identity. `docs/host-protocol.md` → [ssh-sftp](ssh-sftp.md)
- **persistent session** (aka detached session, daemon-owned session) — Session left alive by sessiond so a client can detach, reconnect, and recover its terminal state. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **protected policy** (aka owner policy, current owner policy) — Verified enrollment and permission state used to admit protected host operations and runtime issuance. `docs/host-protocol.md` → [config-secrets](config-secrets.md)
- **recovery mirror** (aka authoritative recovery mirror, daemon mirror) — Daemon-owned terminal snapshot restored on reattach, preserving parser state and scrollback instead of raw bytes alone. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **remote observation** (aka read-only observation) — Bounded read-only access path that exposes selected terminal or target state without granting write control. `docs/remote-observation-protocol.md` → [automation](automation.md)
- **remote session creation** (aka host session creation) — Remote create/attach workflow in HOST that binds a shell to a verified host and current daemon generation. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **screen reflow** (aka primary resize reflow) — Primary-screen resize that reconstructs logical rows and remaps cursor and selection positions through history. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **scrollback** (aka retained history, logical history) — Primary-screen history retained as bounded logical lines with reflow-safe anchors and strict memory accounting. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **secret store boundary** (aka native secret store) — Cross-platform boundary that stores only opaque secret references using the OS keychain and rejects plaintext fallback. `docs/adr/0016-native-secret-store-boundary.md` → [config-secrets](config-secrets.md)
- **session controller** (aka controller, terminal controller) — Object serializing input, resize, and shutdown against one live session while preserving backend generation checks. `app/festerm/src/session_controller.rs::SessionController` → [app-commands](app-commands.md)
- **sessiond** (aka session daemon, persistent daemon) — Per-session local daemon keeping a PTY/ConPTY shell alive and replayable across frontend exits. `AGENTS.md` → [sessions](sessions.md)
- **SFTP** (aka SSH file transfer) — Graphical remote file management surface that keeps local and remote panes separate while preserving connection metadata. `docs/sftp-ui-design.md` → [ssh-sftp](ssh-sftp.md)
- **synthetic backend** (aka test backend, inert backend) — Controlled backend used to exercise ordering without live transport or native qualification. `docs/automation-design.md` → [automation](automation.md)
- **terminal core** (aka core terminal) — Component owning parser state, screen memory, scrollback, and input semantics independent of the GUI. `ARCHITECTURE.md` → [terminal-core](terminal-core.md)
- **terminal snapshot** (aka recovery snapshot, snapshot schema) — Serialized terminal state used for attach and recovery, including parser state, scrollback, and cursor data. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **terminal_replies_owned_by_backend** (aka backend-owned replies) — Flag indicating the backend, not the UI, answers terminal protocol replies while parsing output. `crates/festerm-session/src/lib.rs::terminal_replies_owned_by_backend` → [sessions](sessions.md)
- **Validation-Impact** (aka validation impact) — Required annotation on changes naming affected GUI or ADR edges and the evidence needed for review. `AGENTS.md` → [app-commands](app-commands.md)
- **versioned TOML configuration** (aka config schema, versioned config) — Startup configuration format that validates schema versions and hot-reloads transactionally without external restarts. `docs/adr/0008-versioned-toml-configuration.md` → [config-secrets](config-secrets.md)
- **WARP** (aka Windows WARP) — Windows software rasterizer path used for GPU-agnostic rendering when the supported DX12 CPU adapter qualifies. `docs/development-handoff.md` → [desktop-platform](desktop-platform.md)
- **workflow bundle** (aka workflow manifest) — Validated automation artifact whose immutable digest and parameters are frozen before a run starts. `crates/festerm-automation/README.md` → [automation](automation.md)
