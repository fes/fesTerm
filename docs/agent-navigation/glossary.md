# Glossary

- **alternate screen** (aka alternate buffer) — Terminal buffer that swaps in place of the primary screen and restores the original screen and cursor state on exit. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **automation broker** (aka application-owned automation broker) — Application-owned gate that admits MCP or JavaScript requests and forwards only bounded typed actions to terminals. `docs/automation-design.md` → [automation](automation.md)
- **bounded logical scrollback** (aka anchored viewport) — Scrollback model that bounds memory use, keeps logical lines stable, and anchors viewport navigation under resize. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **daemon-owned lease** (aka durable lease, session lease) — Protected session claim owned by the daemon and checked against generation and attachment identity before reuse. `docs/adr/0084-host-based-dev-tunnels.md` → [sessions](sessions.md)
- **DECSET** (aka DEC private mode) — ANSI DEC private mode selector used to enable or disable terminal behaviors such as mouse tracking and wraparound. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **detached daemon** (aka standalone daemon) — A background session process that outlives the GUI and keeps a PTY running independently of app teardown. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **Direct2D** (aka Direct2D renderer, DX12 CPU path) — Optional Windows renderer that paints the terminal through a DX12 CPU adapter when the target and backend are eligible. `docs/adr/0039-opt-in-direct2d-terminal-composition.md` → [terminal-ui](terminal-ui.md)
- **East Asian width** (aka ambiguous width) — Unicode width policy that distinguishes single- and double-width cells for CJK and ambiguous East Asian characters. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **enrolled HOST** (aka enrolled host) — Host installation that has a protected owner key and local consent, so it can authenticate control and terminal streams. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **grapheme** (aka extended grapheme cluster) — Unicode text unit that preserves combining marks and emoji as one displayable cluster rather than separate cells. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **GUI action graph** (aka action graph) — Machine-checked map of UI flows and their required validation coverage for GUI and ADR changes. `docs/gui-action-graph.md` → [app-commands](app-commands.md)
- **HOST** (aka host service, host runtime, host runtime service) — Configured fesTerm host service that publishes inventory, creates or resumes shells, and enforces owner-bound admission. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-based Dev Tunnel** (aka host-based tunnel, HOST tunnel) — Dev Tunnel flow that reaches a configured local host service instead of a direct ad hoc shell session. `README.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-key trust** (aka known-host fingerprint) — Saved trust decision for a remote host key, used before SSH operations and SFTP sessions are admitted. `docs/configuration.md` → [ssh-sftp](ssh-sftp.md)
- **local PTY** (aka native PTY, pseudoterminal) — Local process-terminal boundary, either Unix PTY or Windows ConPTY, that feeds the session byte stream and resize events. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **named pipe** (aka pipe endpoint) — Local Windows IPC endpoint used by the session daemon to accept a single attach client without network exposure. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **native secret store** (aka platform keychain) — The fixed OS-backed secret service used for opaque SSH password references and other guarded credentials. `docs/adr/0016-native-secret-store-boundary.md` → [config-secrets](config-secrets.md)
- **native vault** (aka secure store) — OS-backed secret store for opaque credentials and protected owner references, kept outside TOML and sync metadata. `README.md` → [config-secrets](config-secrets.md)
- **owner binding** (aka owner key binding) — Association between a host session and the verified owner key that proves the channel is bound to the enrolled host owner. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **owner proof** (aka owner-bound proof, enrolled-owner proof) — Bound owner challenge and proof used to authenticate a host channel before create or attach requests are admitted. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **persistent host-key trust** (aka known-host trust) — Saved SSH host-key trust policy that prevents silent trust changes and requires explicit review for unknown or changed hosts. `docs/adr/0020-persistent-host-key-trust.md` → [ssh-sftp](ssh-sftp.md)
- **profile hosting** (aka installed profile hosting) — Hosting a session behind a saved profile, where a remote host keeps the shell and attaches the terminal on demand. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **recovery mirror** (aka mirror terminal output) — Backend-owned terminal mirror that answers terminal queries and publishes recovery snapshots while the UI suppresses duplicates. `AGENTS.md` → [sessions](sessions.md)
- **remote observation protocol** (aka read-only observation protocol) — Approved view-only protocol that reads exact terminal roots with bounded offsets and generation checks without write authority. `docs/remote-observation-protocol.md` → [automation](automation.md)
- **root filesystem protocol** (aka rooted filesystem protocol) — Explicitly approved host-side root access for file enumeration and transfer, kept separate from general terminal or MCP authority. `README.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **scrollback** (aka terminal history) — Retained terminal output history that supports viewport navigation and logical line recovery across screen updates. `DESIGN.md` → [terminal-core](terminal-core.md)
- **secret boundary** (aka native secret store boundary) — The GUI-independent secret layer that stores only opaque references and zeroizes sensitive bytes in native storage. `docs/adr/0016-native-secret-store-boundary.md` → [config-secrets](config-secrets.md)
- **sessiond** (aka local daemon, persistent daemon) — Standalone fesTerm-owned local session daemon that keeps a PTY alive after the GUI exits. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **SFTP** (aka graphical SFTP, remote file manager) — Secure file-transfer surface for browsing, queueing, and streaming files over an authenticated remote session. `docs/sftp-ui-design.md` → [ssh-sftp](ssh-sftp.md)
- **SSH liveness reconnect** (aka session reconnect) — Reconnect flow that resumes an existing SSH session without replacing it when the transport has dropped but the daemon still owns it. `docs/adr/0018-ssh-liveness-reconnect-and-persistent-session-recovery.md` → [ssh-sftp](ssh-sftp.md)
- **terminal_replies_owned_by_backend** (aka backend-owned replies) — Session capability where the backend, not the frontend terminal, answers protocol replies generated during output parsing. `crates/festerm-session/src/lib.rs::terminal_replies_owned_by_backend` → [sessions](sessions.md)
- **traceability** (aka validation traceability) — Requirement-to-test linkage that keeps GUI changes, ADRs, and automated evidence aligned before handoff. `AGENTS.md` → [automation](automation.md)
- **WARP** (aka WARP renderer) — Windows software rendering path used for offscreen or CPU-backed presentation during native validation and fallback rendering. `docs/manual-validation.md` → [terminal-ui](terminal-ui.md)
- **workflow bundle** (aka automation bundle, workflow manifest) — User-selected automation package whose approved scope, digests, and targets are bound before execution. `docs/automation-design.md` → [automation](automation.md)
