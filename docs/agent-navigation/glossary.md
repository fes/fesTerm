- **app command** (aka semantic command, typed app action) — A central product action that translates user input into one consistent state transition regardless of surface. `docs/application-command-model.md` → [app-commands](app-commands.md)
- **automation admission epoch** (aka admission epoch, grant epoch) — A monotonic generation used to invalidate stale automation approvals and admission state across updates. `crates/festerm-session/src/lib.rs` → [automation](automation.md)
- **automation broker** (aka app-owned broker, native approval broker) — The application-owned automation coordinator that validates adapters, grants, and session operations. `docs/automation-design.md` → [automation](automation.md)
- **bounded recursive planning** (aka transfer planning, queued file plan) — The per-worker cap on queued transfer-row planning and metadata so file copies fail closed instead of overruning memory. `docs/sftp-ui-design.md` → [ssh-sftp](ssh-sftp.md)
- **bounded scrollback** (aka retained history, history budget) — Primary-screen history with a strict byte cap, stable logical lines, and safe trimming on eviction. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **cell footprint** (aka compact cell, cell charge) — The bounded per-cell memory charge retained for terminal text capacity and recovery compatibility. `docs/adr/0081-compact-cells-with-stable-recovery-charges.md` → [terminal-core](terminal-core.md)
- **controller handoff** (aka typed handoff, admission handoff) — The handoff of an exact controller identity and grant through a validated automation admission path. `docs/milestone-progress.md` → [automation](automation.md)
- **DECSET** (aka ANSI mode set, mode set) — The ANSI mode-setting escape that toggles terminal features like margins, wraparound, and pointer reporting. `docs/adr/0037-reverse-wraparound-bounds.md` → [terminal-core](terminal-core.md)
- **Direct2D** (aka native D2D, Direct2D painting) — The Windows native terminal paint path that reuses validated GPU resources for bounded composition. `docs/adr/0039-opt-in-direct2d-terminal-composition.md` → [terminal-ui](terminal-ui.md)
- **enrolled HOST** (aka owner-key HOST, host enrollment) — A HOST instance whose owner identity and host key are explicitly enrolled and checked before grants. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **global ingest budget** (aka window ingest cap, event budget) — A per-window shared time and byte budget that limits synchronous session parsing while preserving ordering. `docs/adr/0079-global-terminal-ingest-budget.md` → [sessions](sessions.md)
- **grapheme width** (aka grapheme sizing, unicode width) — Deterministic Unicode cell sizing based on extended grapheme clusters and pinned width tables. `docs/adr/0026-grapheme-width-and-color-emoji-fallback.md` → [terminal-core](terminal-core.md)
- **GUI action graph** (aka UI route map, action flow) — The traversable user-observable workflow graph that ties GUI actions to recovery and test routes. `docs/gui-action-graph.md` → [app-commands](app-commands.md)
- **history recovery** (aka recovery state, snapshot recovery) — Recovering the terminal state from a bounded snapshot so reattach resumes the same visible and retained history. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **HOST** (aka host service, host endpoint, host runtime, host manager) — A configured fesTerm host service with a stable ID, protected owner binding, and authorized session inventory. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host installation** (aka host setup, setup consent) — The explicit local provisioning and consent flow that installs a protected host and binds its trust state. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-based Dev Tunnel** (aka HOST tunnel, host tunnel) — A tunnel flow that reaches a configured host service rather than a standalone app-specific bridge. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-key trust** (aka known host trust, persistent trust) — The saved SSH host-fingerprint policy that suppresses repeat prompts for trusted destinations. `docs/adr/0020-persistent-host-key-trust.md` → [ssh-sftp](ssh-sftp.md)
- **Job Object** (aka kill-on-close job, Windows job) — The Windows job object used to ensure child processes terminate with the owning session lifecycle. `docs/adr/0025-native-local-session-persistence-daemon.md` → [desktop-platform](desktop-platform.md)
- **known-host trust** (aka known_hosts, host key cache) — The persisted host fingerprint store keyed by host and port, used for silent future SSH acceptance. `docs/adr/0020-persistent-host-key-trust.md` → [ssh-sftp](ssh-sftp.md)
- **local session identity** (aka logical session id, session id) — The stable logical identity used to attach to, resume, or replace a session without reusing stale targets. `docs/adr/0084-host-based-dev-tunnels.md` → [sessions](sessions.md)
- **native session recovery** (aka session recovery, reattach recovery) — The live reattach path that restores the same terminal state instead of replaying raw bytes alone. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **native vault** (aka secure store, keychain store) — The OS-backed secret store that holds opaque references instead of plain SSH secrets or config values. `docs/adr/0016-native-secret-store-boundary.md` → [config-secrets](config-secrets.md)
- **owner proof** (aka owner binding, enrolled owner) — The protected proof that a host or session request came from the configured enrolled owner of that host. `docs/dev-tunnels-experiment.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **persistent daemon** (aka local session daemon, session daemon) — A background service that keeps a terminal alive after the UI process exits and can be reattached later. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **profile hosting** (aka hosted profile, host recipe) — The act of attaching a local or remote profile to an authorized host and preserved session lifecycle. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **recovery mirror** (aka daemon mirror, authoritative mirror) — The daemon-owned terminal snapshot that preserves parser state and screen history across reattach. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **remote observation protocol** (aka MCP observation, bounded protocol) — The constrained observation-only protocol that exposes selected terminal state without granting direct backend access. `docs/remote-observation-protocol.md` → [automation](automation.md)
- **secret store boundary** (aka native secret store, opaque secret refs) — The GUI-independent boundary that stores secrets in OS keychains and exposes opaque references only. `docs/adr/0016-native-secret-store-boundary.md` → [config-secrets](config-secrets.md)
- **session recovery snapshot** (aka terminal snapshot, recovery snapshot) — A length-bounded serialization of terminal state used as the prelude to a reattached session. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **session registration** (aka daemon registry, session registry) — The on-disk registry that tracks live local session daemons, socket paths, and lifecycle metadata. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **sessiond** (aka local daemon, persistence daemon) — Detached local shell daemon that keeps a PTY alive across app exits and exposes reattach recovery. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **SFTP** (aka remote file manager, file transfer) — The file-transfer surface that opens a local/remote two-pane manager over a live SSH session. `docs/sftp-ui-design.md` → [ssh-sftp](ssh-sftp.md)
- **startup lifecycle gate** (aka host readiness, enablement gate) — The requirement that host access remains disabled until native checks, consent, and readiness are verified. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **synthetic backend** (aka fixture backend, inert backend) — A non-production session backend used to test input routing and observation without real transport state. `docs/automation-design.md` → [automation](automation.md)
- **terminal control queue** (aka ordered input queue, bounded command queue) — The ordered command stream that preserves input, resize, and recovery-control ordering under backpressure. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **terminal recording export** (aka MP4 export, recording export) — The recorded terminal source converted into synchronized per-session MP4 artifacts with checked metadata. `docs/adr/0077-synchronized-terminal-recording-and-mp4-export.md` → [recording](recording.md)
- **terminal_replies_owned_by_backend** (aka backend-owned replies, reply ownership) — Signal that the backend, not the UI terminal, answers terminal replies generated while parsing output. `crates/festerm-session/src/lib.rs` → [sessions](sessions.md)
