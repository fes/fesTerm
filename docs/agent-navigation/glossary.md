- **alternate screen** (aka alt screen, alternate buffer) — Separate terminal buffer that suspends primary-screen history and restores it when the user leaves that mode. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **app-owned terminal mutation** (aka single-writer mutation, composition-root mutation) — Terminal changes observed at the app's authoritative boundary, so recording and recovery see the same state as the GUI. `docs/adr/0077-synchronized-terminal-recording-and-mp4-export.md` → [recording](recording.md)
- **application command** (aka AppCommand, command intent) — Typed product action that centralizes UI invocation, lifecycle policy, and session effects in one dispatch path. `docs/application-command-model.md` → [app-commands](app-commands.md)
- **DECSET** (aka private mode, DEC private mode) — ANSI DEC private-mode selectors that turn terminal features on and off, such as mouse tracking or wraparound. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **Dev Tunnel bridge** (aka tunnel bridge, host bridge) — The secured service path that routes authorized session inventory, control, and terminal attachment via a host connection. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **Direct2D** (aka native composition, D2D) — Windows native terminal paint path that reuses the wgpu scene while preserving ordinary egui-wgpu fallback. `docs/adr/0039-opt-in-direct2d-terminal-composition.md` → [desktop-platform](desktop-platform.md)
- **document registry** (aka shared registry, doc registry) — Application-scoped registry that owns document identity, shared text, dirty state, and save-generation coordination. `docs/adr/0034-shared-mutable-text-documents.md` → [documents](documents.md)
- **East Asian width** (aka ambiguous width, CJK width) — Unicode width policy that distinguishes single- and double-width cells for ambiguous CJK and emoji-like characters. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **enrolled HOST** (aka approved host, verified host) — A host installation with protected owner keys and consent, so it can authenticate control and terminal streams. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **grapheme** (aka grapheme cluster, extended grapheme) — A terminal-visible Unicode cluster treated as one width-bearing unit, including emoji and combining sequences. `docs/adr/0026-grapheme-width-and-color-emoji-fallback.md` → [terminal-core](terminal-core.md)
- **GUI action graph** (aka action graph, UI workflow graph) — Machine-readable route map that describes user-visible app flows, state transitions, and recovery edges. `docs/gui-action-graph.md` → [app-commands](app-commands.md)
- **HOST** (aka host service, host protocol, host daemon, configured host) — Host-oriented remote access contract for verified host identity, session inventory, and authenticated control streams. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host key approval** (aka verified host key, approved fingerprint) — Exact host-key approval step that gates inner SSH channel access before owner proof and session creation can proceed. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host session review** (aka reviewed host session, host selection review) — Foreground review step that confirms the exact host, account, and recipe before a protected session can be opened or created. `docs/application-command-model.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **Job Object** (aka Windows job, kill-on-close job) — Windows process/job boundary that can terminate a child process tree when fesTerm shuts down or the session is closed. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **logical history** (aka history model, retained logical lines) — Ordered primary-screen history stored as logical lines with stable identities that survive resize and viewport remapping. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **MP4 export** (aka recording export, final export) — Explicit export step that renders synchronized terminal streams to a user-selected MP4 set and verifies output before publishing. `docs/adr/0077-synchronized-terminal-recording-and-mp4-export.md` → [recording](recording.md)
- **native vault** (aka secure store, secret store) — OS-backed secret store for opaque credentials and protected owner references, kept outside config and sync metadata. `docs/host-protocol.md` → [config-secrets](config-secrets.md)
- **owner proof** (aka owner-bound proof, enrolled-owner proof) — Challenge-and-proof exchange that authenticates a host channel before create or attach requests are admitted. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **owner-auth challenge** (aka channel challenge, proof challenge) — Fresh per-channel challenge used to prove the current owner identity before a host stream is admitted. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **persistence provider** (aka session provider, provider kind) — Backend that keeps a session alive across frontend exits, such as native sessiond, tmux, or screen. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **primary screen** (aka main screen, visible screen) — The session's normal terminal viewport that accumulates visible output and participates in scrollback history. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **protected file store** (aka headless file store, explicit file store) — Headless-only protected credential backend that stores owner references and keys in explicit local private files instead of the native vault. `docs/host-protocol.md` → [config-secrets](config-secrets.md)
- **protected installation journal** (aka owner journal, revision journal) — Durable protected ledger that records enrollment, lifecycle epochs, and safe publication of owner policy or receipt state. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **recording checkpoint** (aka capture checkpoint, render checkpoint) — Bounded visible-state checkpoint stored during capture to resume rendering without importing backend-only terminal state. `docs/adr/0077-synchronized-terminal-recording-and-mp4-export.md` → [recording](recording.md)
- **recording source** (aka private source, source artifact) — Private recording artifact that holds the synchronized session timeline before export and retry decisions. `docs/adr/0077-synchronized-terminal-recording-and-mp4-export.md` → [recording](recording.md)
- **recovery mirror** (aka authoritative mirror, daemon mirror) — Daemon-owned terminal state snapshot that preserves parser and screen state without replaying stale input or replies. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **recovery snapshot** (aka snapshot prelude, attach snapshot) — Serialized terminal state sent before live output so a reconnecting frontend can restore the same terminal state. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **scrollback** (aka history, retained history) — Retained logical terminal output above the visible screen, bounded and remapped on resize and eviction. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **scrollback budget** (aka retained-history budget, history limit) — Configured byte cap that limits retained logical history and preserves deterministic memory bounds per session. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **session manager** (aka daemon session manager, shell manager) — Higher-level session owner that creates detached shells, preserves generation identity, and manages terminal lifetime. `docs/adr/0084-host-based-dev-tunnels.md` → [sessions](sessions.md)
- **sessiond** (aka daemon, local daemon) — Standalone local daemon that owns one PTY/ConPTY shell and keeps it alive across frontend restarts. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **sessiond registry** (aka daemon registry, pid registry) — Small on-disk registry used to list and prune live local daemon sessions and their socket or pipe endpoints. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **shared document** (aka document handle, shared text document) — One underlying file or remote document with multiple views, so edits propagate without disk writes or watcher races. `docs/adr/0034-shared-mutable-text-documents.md` → [documents](documents.md)
- **terminal snapshot** (aka screen snapshot, recovery state) — Bounded terminal state capture used to validate and adopt a recovered view without replaying stale terminal side effects. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **terminal_replies_owned_by_backend** (aka backend replies, reply ownership) — Daemon-owned terminal query replies that are forwarded only once and never replayed after reattach. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **validation traceability** (aka traceability, requirement traceability) — Repository check that links requirements, ADRs, scenarios, and evidence so changes are inspectable and machine-validated. `AGENTS.md` → [app-shell](app-shell.md)
- **WARP** (aka software renderer, WARP path) — Microsoft software rasterizer path that can run Direct2D terminal composition on supported Windows x64 targets. `docs/adr/0039-opt-in-direct2d-terminal-composition.md` → [desktop-platform](desktop-platform.md)
- **workflow manifest** (aka automation manifest, workflow digest) — Immutable workflow description whose allowed scopes, digests, and targets are bound before execution. `docs/automation-design.md` → [automation](automation.md)
