- **alternate screen** (aka alternate buffer, alt screen) — A separate terminal buffer that keeps its own screen state and does not enter primary scrollback unless explicitly restored. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **automation broker** (aka app broker, automation kernel) — The application-owned automation authority that validates scoped requests and routes only bounded terminal observations or typed actions. `docs/automation-design.md` → [automation](automation.md)
- **DECSET** (aka private mode set, mode toggle) — A DEC private-mode set that switches terminal behaviors such as wrap, cursor keys, and mouse tracking at runtime. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **Direct2D** (aka DX12 native paint, native D2D) — The supported Windows Direct2D terminal paint path that composes immutable retained surfaces without moving terminal ownership. `docs/adr/0039-opt-in-direct2d-terminal-composition.md` → [terminal-ui](terminal-ui.md)
- **East Asian width** (aka EAW, wide-cell rule) — The pinned Unicode width policy that resolves ambiguous or wide characters to one or two terminal cells instead of font advance. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **generation** (aka live generation, session generation) — A monotonic session or host generation that distinguishes a live attachment from a stale or replaced shell or grant. `docs/adr/0084-host-based-dev-tunnels.md` → [sessions](sessions.md)
- **grapheme** (aka grapheme cluster, Unicode cluster) — An extended Unicode cluster that is segmented and width-allocated as one unit so combining marks and emoji stay aligned. `docs/adr/0026-grapheme-width-and-color-emoji-fallback.md` → [terminal-core](terminal-core.md)
- **host control** (aka host session control, session control) — The host-side control plane that verifies authority, admission, and generation boundaries before a session is created or resumed. `docs/host-protocol.md` → [sessions](sessions.md)
- **host key trust** (aka known-host trust, host fingerprint, saved host key, trusted fingerprint) — The trust path that validates a host key before SSH or remote session access, rejecting changed or unknown keys before use. `docs/adr/0020-persistent-host-key-trust.md` → [ssh-sftp](ssh-sftp.md)
- **host-based Dev Tunnel** (aka HOST tunnel, dev tunnel host) — A host-centric remote-access model where a configured host service exposes authorized sessions and tunnel endpoints rather than one-off shell setup. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **Job Object** (aka kill-on-close job, Windows job) — The Windows process-group mechanism used to ensure a child session dies when fesTerm closes unless a persistence daemon intentionally escapes it. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **local PTY** (aka native PTY, local shell) — The local process-backed terminal backend that runs a shell via a PTY or ConPTY and owns its lifecycle within the app process. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **markdown viewer** (aka markdown preview, viewer) — The document viewer route that loads, sanitizes, and renders Markdown into a shared document surface with syntax-aware behavior. `docs/markdown-viewer-design.md` → [documents](documents.md)
- **native vault** (aka OS keychain, secret store) — The native platform secret boundary that stores opaque credentials outside TOML and never exposes raw secret content to app code. `docs/adr/0016-native-secret-store-boundary.md` → [config-secrets](config-secrets.md)
- **owner proof** (aka enrolled owner, proof record) — The protected local proof that a host or account binding is tied to an authenticated owner and not just a guessed public metadata record. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **persistence daemon** (aka session daemon, local daemon) — The daemon-owned persistence layer that creates and reuses detached local shells while keeping session ownership separate from the GUI process. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **persistent session** (aka durable shell, attached session) — A shell or session kept alive across frontend exits through an explicit daemon or provider rather than a short-lived process tree. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **primary scrollback** (aka logical history, retained history) — The stored primary-screen history held as logical lines with explicit capacity accounting and anchored viewport behavior. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)

- **recording export** (aka MP4 export, recording output) — The finalized recording path that prepares privacy-gated terminal captures and exports them in a bounded media format. `docs/adr/0077-synchronized-terminal-recording-and-mp4-export.md` → [recording](recording.md)
- **recovery mirror** (aka daemon mirror, mirror) — The daemon-owned terminal snapshot that ingests PTY output and preserves parser state for reattach without replaying stale replies. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)

- **secret reference** (aka opaque secret ref, vault ref) — A TOML-safe opaque identifier that points at a native stored secret without placing secret material or its shape in config files. `docs/adr/0016-native-secret-store-boundary.md` → [config-secrets](config-secrets.md)

- **sessiond** (aka local persistence daemon, daemon) — A standalone local daemon that owns one PTY/ConPTY session and keeps it alive across GUI exits for reattach recovery. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)

- **SSH trust** (aka host approval, known-host gate) — The explicit host-key and credential approval boundary that gates authenticated SSH connection attempts before they execute. `docs/adr/0019-fingerprint-first-ssh-authentication-ordering.md` → [ssh-sftp](ssh-sftp.md)
