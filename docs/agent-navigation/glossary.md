- **generation** (aka backend generation) — Monotonic attachment generation used to reject stale transport or session state after reconnect or replacement. `crates/festerm-admission/src/lib.rs` → [sessions](sessions.md)
- **grapheme** (aka grapheme cluster) — A terminal unit that may contain combining marks or emoji and is sized by Unicode grapheme segmentation and width rules. `docs/adr/0026-grapheme-width-and-color-emoji-fallback.md` → [terminal-core](terminal-core.md)
- **GUI action graph** (aka action graph, UI graph) — Traversable product workflow map that ties observable states, actions, and recovery edges across panes. `docs/gui-action-graph.md` → [app-shell](app-shell.md)
- **history recovery** (aka replay recovery) — Bounded restoration path that rehydrates prior screen and scrollback state after daemon or frontend reattach. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [terminal-core](terminal-core.md)
- **HOST** (aka host service, HOST runtime) — Configured host endpoint and identity that exposes authorized session inventory, control, and attachment routing. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host key trust** (aka known_host trust) — Persisted SSH host-fingerprint decision that accepts a matching host silently and treats key changes as deliberate revalidation. `docs/adr/0020-persistent-host-key-trust.md` → [ssh-sftp](ssh-sftp.md)
- **host-based Dev Tunnel** (aka HOST tunnel) — A dev tunnel that reaches a configured local fesTerm host service and routes authorized remote session creation and control. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)

- **mouse tracking mode** (aka DECSET ?9) — Terminal mode set that selects X10, button-motion, or all-motion mouse reporting under DECSET private modes. `crates/festerm-core/src/modes.rs` → [terminal-core](terminal-core.md)
