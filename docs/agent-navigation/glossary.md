# Glossary

- **alternate screen** (aka alternate buffer, secondary screen) — Separate terminal buffer with no retained history; leaving it restores the hidden primary screen state. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **app-private storage** (aka private recording store, app-managed storage) — Source recordings and staging files remain in app-private storage instead of the export directory for privacy and retry safety. `docs/terminal-recording-design.md` → [recording](recording.md)
- **bounded scrollback** (aka retained history, scrollback budget, history byte budget, retained charge) — Primary-screen history with a strict byte budget, eviction rules, and stable anchor behavior across resizes. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [sessions](sessions.md)
- **cell geometry** (aka terminal cell layout, cell ownership) — Renderer-immutable cell coordinates that control cursor placement, selection, and hit testing. `docs/adr/0012-cell-geometry-owns-ligature-and-fallback-mapping.md` → [terminal-core](terminal-core.md)
- **config save gate** (aka poisoned save gate, save-latch) — In-memory latch that blocks later config saves after an earlier save has failed or become indeterminate. `docs/configuration.md` → [config-secrets](config-secrets.md)
- **configuration schema** (aka versioned TOML, schema v1) — Strict configuration format with explicit versioning, validation, and startup defaults instead of ad hoc reloads. `docs/configuration.md` → [config-secrets](config-secrets.md)
- **controller handoff** (aka broker handoff, typed handoff) — Application-owned broker passes only bounded observations and typed requests to a worker or MCP peer. `docs/automation-design.md` → [automation](automation.md)
- **DECSET** (aka private mode, terminal mode) — Private DEC mode setting that turns a terminal behavior on or off, such as mouse reporting or wrap mode. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **Direct2D** (aka native D2D, GPU terminal path) — Windows native compositor used on supported WARP-qualified hosts to paint terminal frames without full egui fallback. `docs/adr/0039-opt-in-direct2d-terminal-composition.md` → [terminal-ui](terminal-ui.md)
- **East Asian Ambiguous width** (aka Ambiguous width, width table) — Width policy that treats East Asian ambiguous characters as one cell unless a configured policy changes it. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **enrolled owner** (aka owner binding, verified owner) — Explicitly enrolled host owner whose protected keys and consent are checked before a host service may issue grants. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **fenced session grant** (aka exact session grant, generation-bound grant) — Grant that stays bound to the exact session generation and must be revalidated before attach or create actions proceed. `docs/automation-design.md` → [automation](automation.md)
- **generation** (aka daemon generation, live generation) — Exact session or daemon incarnation used to pin attach, revoke, and recovery behavior to the correct live instance. `docs/host-protocol.md` → [sessions](sessions.md)
- **grapheme cluster** (aka extended grapheme, grapheme) — Unicode unit that keeps combining marks, ZWJ sequences, and emoji fragments in one terminal cell. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **GUI action graph** (aka action edges, UI route graph) — Graph of interactive UI edges and validation coverage that ties a behavior to its command, view, and tests. `docs/gui-action-graph.md` → [app-commands](app-commands.md)
- **headless host** (aka host-local policy, configured host) — Host configuration mode that stores local policy in protected host-local state instead of portable TOML profile metadata. `docs/headless-host.md` → [desktop-platform](desktop-platform.md)
- **HOST** (aka host service, host protocol, host runtime, host controller) — Host-oriented dev-tunnel and remote-session model that binds a tunnel to a verified host and session identity. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host recipe** (aka portable recipe, saved recipe) — Metadata-only host configuration that preserves a logical session target and launch intent without a secret payload. `docs/configuration.md` → [config-secrets](config-secrets.md)
- **host-based Dev Tunnel** (aka HOST tunnel, HOST session) — Host-oriented tunnel model that separates discovery, inventory, and terminal attachment from legacy bridge behavior. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **Job Object** (aka kill-on-close job, process job) — Windows job that can terminate a child process tree when fesTerm exits, except for explicitly detached daemons. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **ligature policy** (aka cell-run shaping, fallback mapping) — Opt-in shaping rule that keeps ligatures and fallback glyphs from changing terminal cell ownership. `docs/adr/0012-cell-geometry-owns-ligature-and-fallback-mapping.md` → [terminal-core](terminal-core.md)
- **local-session persistence** (aka daemon-backed persistence, durable local session) — Session model that retains shell lifetime across app exit by using a separate session daemon instead of the GUI process. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **logical line** (aka retained logical row, history line) — Primary-screen history unit that preserves hard breaks, soft wraps, and stable cursor positions through reflow. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **MP4 export** (aka session export, recording export) — Per-session MP4 rendering from a synchronized recording, with explicit naming and verification before publication. `docs/terminal-recording-design.md` → [recording](recording.md)
- **native vault** (aka protected vault, secret store) — Platform-native secure store for owner keys, protected policy state, and opaque secret references. `docs/configuration.md` → [config-secrets](config-secrets.md)
- **owner proof** (aka owner-auth, enrolled-owner proof, owner proof flow, enrolled owner auth) — Challenge-and-proof exchange that verifies the configured owner before a host or session grants control. `docs/host-protocol.md` → [ssh-sftp](ssh-sftp.md)
- **path-admission check** (aka safe filename check, remote-to-local admission) — Lexical path validation that rejects unsafe or invalid local names before a remote file is downloaded or renamed. `docs/sftp-ui-design.md` → [ssh-sftp](ssh-sftp.md)
- **principal grant** (aka native grant, approved scope) — Bound permission record that names allowed operations, targets, deadlines, and data recipients for an automation actor. `docs/automation-design.md` → [automation](automation.md)
- **privacy gate** (aka recording privacy, capture safety gate) — Capture-state check that blocks a recording when the app is backgrounded, locked, or otherwise unsafe. `docs/terminal-recording-design.md` → [recording](recording.md)
- **public host recipe** (aka portable host metadata, offline recipe) — Portable metadata record describing a host session target without carrying secrets or grant authority. `docs/configuration.md` → [config-secrets](config-secrets.md)
- **recovery mirror** (aka authoritative mirror, snapshot mirror) — Daemon-owned terminal snapshot that restores exact parser state across a frontend reconnect or reattach. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **session inventory** (aka authorized inventory, host inventory) — Protected list of sessions and capabilities filtered by the current host, principal, and generation before publication. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **sessiond** (aka daemon, local persistence daemon) — Standalone local-session daemon that keeps one PTY alive and exposes attach, list, and kill operations. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **SFTP transfer manager** (aka file transfer worker, transfer queue) — GUI-backed file-transfer coordinator that applies bounded queue limits, collision checks, and cleanup before a transfer is committed. `docs/sftp-ui-design.md` → [ssh-sftp](ssh-sftp.md)
- **synchronized recording** (aka shared timeline recording, multi-session capture) — Single recording that captures selected terminal sessions on one monotonic timeline and exports them in sync. `docs/terminal-recording-design.md` → [recording](recording.md)
- **terminal output mirror** (aka daemon-owned output, authoritative output) — Output copy owned by the backend so attachment recovery never replays stale terminal replies or GUI-only side effects. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **terminal snapshot** (aka recovery snapshot, screen snapshot) — Serialized terminal state used for deterministic recovery, attach adoption, and full-state reattach validation. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [terminal-core](terminal-core.md)
- **viewport anchor** (aka history anchor, follow state) — Stable scrollback position that keeps the visible viewport attached to a logical row while history is retained or evicted. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-ui](terminal-ui.md)
- **WARP** (aka software rasterizer, DX12 CPU adapter) — Microsoft software DX12 rasterizer used as the eligible Windows CPU-render path for terminal composition. `docs/adr/0039-opt-in-direct2d-terminal-composition.md` → [desktop-platform](desktop-platform.md)
- **workflow bundle** (aka JavaScript bundle, MCP bundle) — User-selected script or workflow payload that is validated, bound to a principal grant, and executed under strict budgets. `docs/automation-design.md` → [automation](automation.md)
