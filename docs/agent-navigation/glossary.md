- **host key fingerprint** (aka known host fingerprint) — The SHA-256 fingerprint used to persist or compare a trusted SSH host key across reconnects. `docs/adr/0020-persistent-host-key-trust.md` → [ssh-sftp](ssh-sftp.md)
- **host key trust** (aka known host trust) — The persistent SSH host-key decision used to accept or reject a server fingerprint without prompting on later reconnects. `docs/adr/0020-persistent-host-key-trust.md` → [ssh-sftp](ssh-sftp.md)
- **Job Object** (aka kill-on-close job) — A Windows process-group mechanism used to ensure a child terminal or daemon is terminated when the owning app closes. `docs/adr/0025-native-local-session-persistence-daemon.md` → [desktop-platform](desktop-platform.md)
- **local session persistence daemon** (aka sessiond daemon) — A standalone helper that owns a detached local shell and preserves a terminal across app restarts and reconnects. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **markdown preview** (aka Preview mode) — A bounded, read-only Markdown presentation that loads a saved or remote document and keeps it separate from terminal editing. `docs/markdown-viewer-design.md` → [documents](documents.md)
- **native vault** (aka secret store) — The native OS keychain or credential-store boundary that holds secret material outside configuration and sync metadata. `docs/adr/0016-native-secret-store-boundary.md` → [config-secrets](config-secrets.md)
- **owner enrollment** (aka enrolled owner) — The explicit local creation of a host-specific owner signing key and permission record before remote host actions can proceed. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **owner proof** (aka verified owner binding) — A cryptographic proof binding a host request to the correct enrolled owner key before session or tunnel actions proceed. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **owner verifier** (aka runtime owner verifier) — The runtime verifier that checks the current protected owner policy and issues an admission guard for host operations. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **profile hosting** (aka installed-profile hosting) — A local profile that binds a tunnel or session to a hosted profile and its durable lifetime rules. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
