- **bounded ingest** (aka shared ingest budget) — Per-window terminal parsing cap that rotates busy sessions and keeps UI-thread work bounded across multiple tabs. `docs/adr/0079-global-terminal-ingest-budget.md` → [terminal-core](terminal-core.md)
- **cell footprint** (aka compact cells) — In-memory per-cell charge that preserves recovery accounting without increasing retained history beyond the legacy budget. `docs/adr/0081-compact-cells-with-stable-recovery-charges.md` → [terminal-core](terminal-core.md)
- **controller handoff** (aka reviewed handoff) — Explicit review handoff that freezes the exact controller target, grant, and input before admission or control transfer. `docs/milestone-progress.md` → [automation](automation.md)
- **DECSET** (aka terminal mode) — DEC private-mode set used for cursor, wrap, mouse, focus, and paste features in terminal parsing and state. `crates/festerm-core/src/modes.rs` → [terminal-core](terminal-core.md)
- **Direct2D** (aka native paint) — Windows native terminal composition path that redraws supported terminal surfaces through Direct2D and shared GPU resources. `docs/adr/0039-opt-in-direct2d-terminal-composition.md` → [desktop-platform](desktop-platform.md)
- **East Asian width** (aka ambiguous width) — Policy that keeps ambiguous East Asian characters at one cell unless the terminal explicitly allocates a wider run. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **enrolled HOST** (aka verified host) — A host configuration that has explicit local owner enrollment and protected key approval before it can serve sessions. `docs/dev-tunnels-experiment.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **generation** (aka daemon generation) — Exact live daemon incarnation used to pin a session or host attachment to the correct runtime and prevent stale replay. `docs/host-protocol.md` → [sessions](sessions.md)
- **grapheme** (aka cluster) — Extended Unicode grapheme cluster that preserves combining marks and emoji sequences as one terminal unit. `docs/adr/0026-grapheme-width-and-color-emoji-fallback.md` → [terminal-core](terminal-core.md)
- **GUI action graph** (aka action graph) — Traversal of user-observable GUI workflows and recovery paths, linking actions to their state transitions and evidence. `docs/gui-action-graph.md` → [app-commands](app-commands.md)
- **HOST** (aka host service, configured host) — Protected host protocol and runtime boundary for secure session inventory, create, attach, and ownership validation. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host recipe** (aka profile recipe) — Portable metadata record that names a host, launch target, and session behavior without storing secrets or direct access grants. `docs/configuration.md` → [config-secrets](config-secrets.md)
- **host runtime** (aka runtime adapter) — Authenticated host runtime adapter that binds channel role, owner proof, and protected session control before serving requests. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-based Dev Tunnel** (aka Dev Tunnel) — Host-oriented remote-access workflow that binds a tunnel to a host service, session inventory, and protected owner approval. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **Job Object** (aka KILL_ON_JOB_CLOSE) — Windows Job Object used to make child PTY processes terminate with the parent job and avoid orphaned shells. `crates/festerm-windows-job/src/lib.rs::WindowsJob` → [desktop-platform](desktop-platform.md)
- **native secret store** (aka secret boundary, native secret store boundary) — Cross-platform secret boundary that stores opaque SSH credential references outside config files and workspace metadata. `docs/adr/0016-native-secret-store-boundary.md` → [config-secrets](config-secrets.md)
- **native vault** (aka secure store) — Platform keychain or credential-store boundary that keeps owner keys, tokens, and other protected secrets outside TOML. `docs/host-protocol.md` → [config-secrets](config-secrets.md)
- **owner proof** (aka owner binding) — A bound challenge-response proving a caller controls the enrolled host owner key for the current session or operation. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **owner-auth** (aka owner auth) — Optional bridge feature that adds explicit owner challenge/proof handling without changing default host listeners or legacy frames. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **PowerShell enterprise boundary** (aka PSRP boundary) — Boundary that keeps PSRP/CLIXML and enterprise identity separated from the terminal session and local daemon model. `docs/adr/0082-native-powershell-enterprise-and-sessiond-boundaries.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **profile hosting** (aka hosted profile) — Desktop host workflow that starts or resumes a protected remote shell from a saved profile while preserving the logical session identity. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **recovery mirror** (aka backend-owned terminal) — Daemon-owned terminal snapshot that answers recovery queries while the frontend suppresses duplicate reply traffic. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **remote observation** (aka metadata-only view) — Read-only observation path that exposes bounded session metadata or events without granting terminal contents or write authority. `docs/remote-observation-protocol.md` → [automation](automation.md)
- **scrollback** (aka retained history) — Primary-screen history retained as bounded logical lines with stable anchors and resize-safe reflow. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **session contract** (aka runtime contract) — Portable session API that defines IDs, I/O, resize, lifecycle, and backend boundaries without embedding terminal parser state. `crates/festerm-session/src/lib.rs` → [sessions](sessions.md)
- **session lifecycle** (aka runtime session) — Session contract covering IDs, I/O, resize, shutdown, and backend transitions without tying the app to one transport. `crates/festerm-session/src/lib.rs` → [sessions](sessions.md)
- **sessiond** (aka local daemon, persistent daemon) — Per-session local daemon that keeps a PTY alive across app exits and reattaches through explicit adoption. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **SFTP** (aka SSH file transfer) — Secure file-transfer protocol used for remote file browsing, streaming, and transfer management within the app. `docs/sftp-ui-design.md` → [ssh-sftp](ssh-sftp.md)
- **synthetic backend** (aka test backend) — In-memory or modeled backend used in automation tests to exercise grant gates and direct input without native delivery. `docs/automation-design.md` → [automation](automation.md)
- **terminal recording** (aka recording session) — Privacy-gated capture of terminal output and appearance used for synchronized replay, export prep, and recovery-safe retention. `docs/terminal-recording-design.md` → [recording](recording.md)
- **terminal_replies_owned_by_backend** (aka backend-owned replies) — Session capability meaning the backend, not the frontend terminal, answers terminal replies generated during output parsing. `crates/festerm-session/src/lib.rs::terminal_replies_owned_by_backend` → [sessions](sessions.md)
- **WARP** (aka CPU adapter) — Microsoft software rasterizer path used for supported Windows x64 terminal rendering and replay validation. `docs/manual-validation.md` → [desktop-platform](desktop-platform.md)
- **workflow bundles** (aka source bundles) — Frozen automation packages with manifest, modules, and schema that are hashed, approved, and executed from an immutable snapshot. `docs/automation-design.md` → [automation](automation.md)
