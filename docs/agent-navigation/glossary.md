- **daemon-owned leases** (aka protected lease, session lease, guarded lease, authority lease) — Protected session grants that keep the daemon's current ticket, writer epoch, and generation under a reviewed lease. `ARCHITECTURE.md` → [sessions](sessions.md)
- **DECSET** (aka private mode, DEC private mode) — Private DEC mode selection such as ?9 and ?1006, which flips mouse, wrap, and keypad behavior. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **Dev Tunnel bridge** (aka bridge relay, tunnel relay) — The session-bridge component that routes host control and terminal traffic between the client and detached shell runtime. `docs/adr/0053-separate-dev-tunnels-session-bridge.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **Direct2D** (aka native composition, D2D) — The opt-in Direct2D composition path for terminal pixels, used behind feature gates and explicit native validation. `docs/adr/0039-opt-in-direct2d-terminal-composition.md` → [terminal-ui](terminal-ui.md)
- **East Asian width** (aka ambiguous width, width policy) — The width policy that treats East Asian ambiguous characters as one cell to keep terminal geometry deterministic. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **enrolled HOST** (aka enrolled host, verified host) — A host that has completed owner enrollment and channel binding under the current protected policy and local trust. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **grapheme** (aka extended grapheme, cluster) — A completed Unicode cluster that owns one or two terminal cells according to width rules and UAX 29 segmentation. `docs/adr/0026-grapheme-width-and-color-emoji-fallback.md` → [terminal-core](terminal-core.md)
- **GUI action graph** (aka action graph, UI action graph) — The traversable GUI workflow graph that maps observable product states and recovery edges across panes and actions. `docs/gui-action-graph.md` → [app-shell](app-shell.md)
- **history recovery** (aka recovery history, replay recovery) — The bounded restoration path that rehydrates prior screen and scrollback state after a frontend or daemon reattach. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [terminal-core](terminal-core.md)
- **HOST** (aka host service, shared host, configured host, host runtime) — A configured fesTerm host service instance with a stable host ID, account binding, and inventory rather than a generic machine name. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-based Dev Tunnel** (aka HOST tunnel, host tunnel) — The host-oriented Dev Tunnels model where service-backed host instances own discovery, authorization, and session routing. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-key trust** (aka known host, key trust) — The saved SSH host-key record that persists a verified fingerprint to suppress repeat prompts for the same destination. `docs/adr/0020-persistent-host-key-trust.md` → [ssh-sftp](ssh-sftp.md)
- **Job Object** (aka Windows Job Object, kill-on-close job) — The Windows Job Object used to keep a child process tree rooted to the same lifetime as a terminal session. `docs/adr/0025-native-local-session-persistence-daemon.md` → [desktop-platform](desktop-platform.md)
- **local session persistence daemon** (aka persisted local daemon, sessiond daemon) — The opt-in standalone daemon for recovered local sessions, distinct from the in-process PTY worker model. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **native vault** (aka OS vault, secret vault) — The OS-native secure store that isolates private key material and other secrets from ordinary TOML and logs. `ARCHITECTURE.md` → [config-secrets](config-secrets.md)
- **owner proof** (aka channel owner proof, owner binding) — A signed channel proof that binds the SSH stream to the exact local approved host, owner, and current challenge. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **privacy gate** (aka recording warning, capture warning) — The pre-flight warning and consent gate that tells users a recording may include echoed secrets and OSC payloads. `docs/terminal-recording-design.md` → [recording](recording.md)
- **profile hosting** (aka hosted profile, profile session) — The saved local profile flow that prepares a session or tunnel on a host without turning metadata into authority. `docs/adr/0084-host-based-dev-tunnels.md` → [config-secrets](config-secrets.md)
- **publisher identity** (aka publisher cert, signing identity) — The package-signing identity that must match the certificate used by the build before update or install trust is accepted. `docs/app-store-distribution-plan.md` → [desktop-platform](desktop-platform.md)
- **recovery mirror** (aka authoritative mirror, daemon mirror) — The daemon's authoritative terminal copy that preserves parser state and recovery across reconnects. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **recovery snapshot** (aka authoritative snapshot, attach snapshot) — A serialized terminal snapshot sent before live output so a new client can adopt the daemon's exact state. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **scrollback** (aka history buffer, terminal history) — Bounded terminal history kept in the model; ADR 0017 defines its logical scrollback and anchored viewport semantics. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **secret boundary** (aka credential boundary, native secret boundary) — The OS-native credential boundary that isolates private values from configuration metadata and ordinary logs. `docs/adr/0016-native-secret-store-boundary.md` → [config-secrets](config-secrets.md)
- **session generation** (aka generation ID, live generation) — The monotonic live session generation ID that marks a specific daemon or backend attachment rather than a PID. `docs/host-protocol.md` → [sessions](sessions.md)
- **sessiond** (aka session daemon, local persistence daemon) — Standalone local daemon that owns one PTY/ConPTY shell and exposes a local-only IPC surface with recovery snapshots. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **SFTP** (aka GUI SFTP, remote files) — A graphical SFTP application surface that opens alongside an SSH terminal and uses verified host and auth metadata. `docs/sftp-ui-design.md` → [ssh-sftp](ssh-sftp.md)
- **single-writer admission** (aka one-writer rule, single live writer) — The rule that exactly one front-end writer may be attached at a time and later attaches steal ownership. `ARCHITECTURE.md` → [sessions](sessions.md)
- **snapshot schema version** (aka schema version, terminal snapshot schema) — The explicit format version for the recovery snapshot, with schema-2 and schema-3 handling and validation. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **steal-on-reconnect** (aka single active client, attach takeover) — The policy that a new attach may displace the previous client when a session is already active. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **terminal parser state** (aka parser state, screen state) — The live terminal model of screen state, cursor, margins, wrap, and input mode that must survive replay and recovery. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [terminal-core](terminal-core.md)
- **terminal query ownership** (aka query reply ownership, backend query owner) — The backend-owned reply path that answers terminal queries such as DSR/DA while suppressing duplicate frontend replies. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [terminal-core](terminal-core.md)
- **terminal recording** (aka session recording, recorded terminal) — An explicit terminal recording workflow that captures selected sessions to a synchronized MP4 export on a shared timeline. `docs/terminal-recording-design.md` → [recording](recording.md)
- **terminal recovery** (aka recovery path, session recovery) — The controlled reattach path that restores terminal state without replaying device queries, stale input, or invalid screen history. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
