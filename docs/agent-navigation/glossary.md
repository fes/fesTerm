- **bounded scrollback** (aka history budget, retained-history cap) — Retained history is limited by a configured charged-byte budget and evicted oldest logical lines first. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)

- **config schema** (aka versioned TOML, schema version 1) — Strict, versioned configuration layout that is validated whole-document before being applied or saved. `docs/configuration.md` → [config-secrets](config-secrets.md)

- **Direct2D** (aka native D2D, Direct2D painter) — Windows-native terminal composition path that installs a Direct2D terminal painter when the adapter qualifies. `app/festerm/src/direct2d.rs` → [desktop-platform](desktop-platform.md)
- **East Asian width** (aka EAW, wide-cell policy) — Unicode width policy that assigns one or two terminal cells without depending on font metrics. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **enrolled HOST** (aka enrolled host, host enrollment) — Explicitly enrolled per-host owner key and policy state that can be checked before remote session creation or attachment. `docs/dev-tunnels-experiment.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **generation lease** (aka lease-backed generation, held generation) — Exact generation token that prevents stale writers from taking over a session or reusing a dead reservation. `docs/adr/0084-host-based-dev-tunnels.md` → [sessions](sessions.md)
- **grapheme** (aka extended grapheme, cluster) — UAX 29 grapheme cluster that keeps combining and emoji sequences aligned as one terminal unit. `docs/adr/0026-grapheme-width-and-color-emoji-fallback.md` → [terminal-core](terminal-core.md)
- **GUI action graph** (aka action graph, app route graph) — Explicit map of user and system actions, edges, and outcomes used to route commands and validate UI behavior. `docs/gui-action-graph.md` → [app-shell](app-shell.md)

- **HOST** (aka HOST v1, host protocol) — Host-oriented remote access protocol that authenticates a configured service, bound session inventory, and protected session creation. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host recipe** (aka public host recipe, portable host recipe) — Portable metadata object describing a host target, launch settings, and future-session behavior without carrying secrets. `docs/configuration.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host service** (aka host bridge, shared host service) — Configured service instance that authenticates a host, exposes inventory, and routes session creation and attachment. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)

- **local session persistence** (aka local persistence, session persistence) — Opt-in daemon-backed local session model that keeps a shell alive after the GUI exits without relying on tmux or screen. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)

- **primary-screen history** (aka primary history, logical history) — Ordered logical lines retained from the primary screen, preserved across resize and selection remapping. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **profile hosting** (aka installed-profile hosting, hosted profile) — Mechanism for exposing a persistent local profile as a remotely addressable session under a verified host service. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
