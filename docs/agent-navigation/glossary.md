- **document registry** (aka shared document set) — The application-scoped registry that owns document identity and keeps tabs, editors, and previews synchronized on the same file state. `docs/adr/0034-shared-mutable-text-documents.md` → [documents](documents.md)

- **grapheme** (aka cluster) — A user-perceived character sequence, such as a combining mark or emoji cluster, treated as one terminal unit for width and cell layout. `docs/adr/0026-grapheme-width-and-color-emoji-fallback.md` → [terminal-core](terminal-core.md)
