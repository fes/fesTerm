- **cell footprint** — Stable in-memory cost of one terminal cell, kept conservative to preserve recovery and history accounting. `docs/adr/0081-compact-cells-with-stable-recovery-charges.md` → [terminal-core](terminal-core.md)
- **controller handoff** — Explicit transfer of terminal-control authority between app/controller instances with validation and generation checks. `docs/automation-design.md` → [automation](automation.md)
- **DECSET** (aka private mode, DEC mode) — Private DEC toggle that enables or disables terminal behaviors such as cursor keys, paste wrappers, or mouse reporting. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **Dev Tunnel bridge** — Relay that binds a remote shell to the exact session generation and owner proof while preserving the daemon's single-writer contract. `crates/festerm-sessiond/src/lib.rs` → [tunnels-enterprise](tunnels-enterprise.md)
- **Direct2D** (aka native composition, D2D) — Windows native composition path that draws terminal content on the supported WARP route without moving terminal ownership into the renderer. `docs/adr/0039-opt-in-direct2d-terminal-composition.md` → [terminal-ui](terminal-ui.md)
- **East Asian width** (aka ambiguous width, EAW) — Width policy for ambiguous East Asian code points, pinned to the terminal width rules and non-CJK behavior. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **generation** (aka daemon generation, live generation) — Daemon incarnation ID that pins ownership, attachment, and lifecycle checks to the exact live session instance. `docs/host-protocol.md` → [sessions](sessions.md)
- **grapheme** (aka extended grapheme, grapheme cluster) — Extended Unicode cluster treated as one terminal unit so width, wrap, and emoji remain stable across fragmented UTF-8. `docs/adr/0026-grapheme-width-and-color-emoji-fallback.md` → [terminal-core](terminal-core.md)
- **GUI action graph** — Map of user-visible GUI routes, validation gates, and recovery edges that defines product behavior and evidence. `docs/gui-action-graph.md` → [app-shell](app-shell.md)
- **HOST** (aka HOST v1, host protocol, HOST contract) — Protected host contract that authenticates owner proof and exact generation before terminal or control activity. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-based Dev Tunnel** (aka host tunnel) — User-owned host service reachable through a verified local Dev Tunnel endpoint and exact generation binding. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-key trust** (aka known-host trust, persistent trust) — Persisted SSH server-fingerprint trust that accepts a matching key without prompting on later reconnects. `docs/adr/0020-persistent-host-key-trust.md` → [ssh-sftp](ssh-sftp.md)
- **Job Object** — Windows job object that can terminate a child process tree when fesTerm closes, unless a detached daemon opts out. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **local-first sync metadata** — Optional sync for non-secret profile metadata that remains outside the core terminal and secret storage model. `docs/adr/0003-local-first-sync-metadata-not-secrets.md` → [config-secrets](config-secrets.md)
- **managed hosting** — Protected service-hosting model that keeps host identity, lifecycle generation, and install state explicit and reviewable. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **markdown viewer** — Bounded read-only Markdown surface that opens local or remote documents without becoming an editor or browser. `docs/markdown-viewer-design.md` → [documents](documents.md)

- **persistent host-key trust** — Saved SSH fingerprint policy that remains across reconnects and is not treated as a secret or configuration value. `docs/adr/0020-persistent-host-key-trust.md` → [ssh-sftp](ssh-sftp.md)

- **profile hosting** — Saved remote session metadata and launch recipe without being the live shell itself. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **recovery mirror** (aka authoritative mirror, daemon mirror) — Daemon-owned terminal snapshot used to restore parser and screen state on reattach without replaying stale replies. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **recovery snapshot** — Bounded serialized terminal state sent at attach time so a reconnect restores the live session without replaying stale input. `docs/adr/0038-sessiond-terminal-recovery-snapshots.md` → [sessions](sessions.md)
- **scrollback** (aka history buffer, retained history, history recovery, recovery history) — Retained terminal history kept for view, selection, and recovery, with bounded logical rows and eviction. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **secret boundary** — Layer that stores opaque secrets in native secure storage and keeps them out of ordinary TOML metadata. `docs/adr/0016-native-secret-store-boundary.md` → [config-secrets](config-secrets.md)
- **session discovery** — Registry and inventory process that finds live sessions and their exact generation before attach or takeover. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **session recovery** — Process that reconnects to a still-running session and restores the authoritative state without replaying stale terminal replies. `docs/adr/0018-ssh-liveness-reconnect-and-persistent-session-recovery.md` → [sessions](sessions.md)
- **sessiond** (aka session daemon, local daemon) — Standalone local daemon that owns one PTY/ConPTY shell and its detach/reconnect lifecycle independent of the GUI. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
