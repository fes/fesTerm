# Glossary

- **application command** (aka AppCommand, typed command) — Central user-visible intent that routes through the coordinator instead of being reimplemented by individual widgets. `docs/application-command-model.md` → [app-commands](app-commands.md)
- **automatic save gate** (aka save gate, poisoned save gate) — In-process save gate that blocks further saves after an indeterminate config write and warns live windows until restart. `docs/configuration.md` → [config-secrets](config-secrets.md)
- **controller handoff** (aka broker handoff, handoff gate) — Application-owned transfer of control from the coordinator to an approved worker without exposing backend objects to the UI layer. `docs/milestone-progress.md` → [automation](automation.md)
- **daemon-owned shell** (aka daemon-owned lease, owned shell) — Shell whose lifetime is controlled by the daemon rather than the UI, so reconnect and recovery continue after GUI exit. `docs/host-protocol.md` → [sessions](sessions.md)
- **DECSET** (aka private mode, DECSLRM) — Terminal private-mode setting such as reverse wraparound or pointer tracking that changes parser and screen behavior. `docs/adr/0037-reverse-wraparound-bounds.md` → [terminal-core](terminal-core.md)
- **Direct2D** (aka Windows D2D, native painter) — Windows native terminal painter that installs a Direct2D composition path when the adapter and format are eligible. `app/festerm/src/direct2d.rs` → [terminal-ui](terminal-ui.md)
- **East Asian width** (aka ambiguous width, east-asian ambiguous) — Deterministic terminal cell width for East Asian ambiguous code points, pinned to one or two cells independent of font choice. `docs/standards-and-implementation-notes.md` → [terminal-core](terminal-core.md)
- **enrolled owner** (aka enrolled HOST, owner enrollment) — A host owner whose key or binding is explicitly enrolled and accepted before protected host operations can proceed. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **exact-generation attach** (aka generation-pinned attach, exact attach) — Attach path that pins both the logical session and exact generation before adopting the live terminal state. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **foreground approval** (aka reviewed approval, explicit confirmation) — Application-owned explicit review and confirmation required before a protected action can proceed or publish a live attachment. `docs/application-command-model.md` → [app-commands](app-commands.md)
- **generation** (aka session generation, daemon generation) — Exact live-generation identity that fences attach, create, and detach operations against stale or replaced sessions. `docs/host-protocol.md` → [sessions](sessions.md)
- **grapheme** (aka extended grapheme, cluster) — A Unicode grapheme cluster whose width and cell ownership are determined before rendering rather than by font shaping. `docs/adr/0026-grapheme-width-and-color-emoji-fallback.md` → [terminal-core](terminal-core.md)
- **GUI action graph** (aka action graph, UI route map) — Traversable map of user-observable GUI workflows and recovery paths that names concrete UI and state transitions. `docs/gui-action-graph.md` → [app-commands](app-commands.md)
- **HOST** (aka host protocol, HOST v1) — Explicit host protocol for authenticated session inventory, creation, attach, and lifecycle fencing with generation checks. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host recipe metadata** (aka public host recipe, recipe metadata, host recipe, portable recipe) — Portable public metadata for host inventory and session selection without granting trust, secret, or creation authority. `docs/configuration.md` → [config-secrets](config-secrets.md)
- **host verification** (aka host-key trust, fingerprint check) — Verification path that checks the saved host key or owner binding before a host session is trusted or created. `docs/host-protocol.md` → [ssh-sftp](ssh-sftp.md)
- **host-based Dev Tunnel** (aka host tunnel, dev tunnel host) — A host-oriented tunnel workflow where the service owns session inventory, creation, and controlled attachment instead of ad hoc scripts. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **Job Object** (aka kill-on-close job, Windows job) — Windows Job Object used to ensure child processes terminate when the owning session or app closes. `crates/festerm-windows-job/src/lib.rs::assign_to_process` → [desktop-platform](desktop-platform.md)
- **local profile** (aka saved local profile, profile metadata) — Saved local launch profile that defines a shell, environment, and session defaults without creating a host-level grant. `docs/configuration.md` → [config-secrets](config-secrets.md)
- **local PTY** (aka local shell, pty worker) — In-process local PTY worker that runs and shuts down a terminal process without a separate persistence daemon. `docs/adr/0025-native-local-session-persistence-daemon.md` → [terminal-core](terminal-core.md)
- **native vault** (aka vault store, protected store) — Protected native keystore that keeps owner and session receipts outside portable config and user-visible profile metadata. `docs/host-protocol.md` → [config-secrets](config-secrets.md)
- **owner proof** (aka owner binding, principal proof) — Cryptographic proof that the client has the verified owner identity required before a host admits protected control. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **persistent daemon** (aka session persistence, daemon owner) — A separate process that owns a shell lifetime beyond the GUI and keeps its terminal output and recovery state alive. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **profile hosting** (aka installed profile host, local profile host) — Explicit local-profile hosting flow that saves installation intent and revalidates the exact profile before background work. `docs/application-command-model.md` → [app-shell](app-shell.md)
- **protected owner receipt** (aka owner receipt, native receipt) — Protected signed receipt tracking the exact owner binding and native policy state used for a reviewed host operation. `docs/application-command-model.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **recovery mirror** (aka recovery sync, mirror_terminal_output) — Backend-owned terminal-state mutation that mirrors recovery state in session order instead of raw shell bytes. `crates/festerm-session/src/lib.rs` → [sessions](sessions.md)
- **remote observation** (aka observation-only grant, read-only observation) — Restricted read-only observation path whose metadata and output are bounded by exact target and grant checks. `docs/remote-observation-protocol.md` → [automation](automation.md)
- **scrollback** (aka retained history, history buffer, history retention, logical history) — Primary-screen history retained as ordered logical lines with a strict configured byte budget and eviction rules. `docs/adr/0017-bounded-logical-scrollback-and-anchored-viewports.md` → [terminal-core](terminal-core.md)
- **session lifecycle** (aka lifecycle boundary, backend lifecycle) — Runtime lifecycle boundary across session startup, output, resize, shutdown, and recovery events for the application layer. `crates/festerm-session/src/lib.rs` → [sessions](sessions.md)
- **sessiond** (aka session daemon, daemon) — Standalone local-session daemon that keeps one PTY alive after the GUI exits and exposes attach, list, and kill operations. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
- **SFTP** (aka secure file transfer, remote file transfer) — SSH-backed file-transfer subsystem used for remote file browsing, transfer, and authenticated file operations. `docs/sftp-ui-design.md` → [ssh-sftp](ssh-sftp.md)
- **synthetic backend** (aka model backend, simulated backend) — Modeled automation backend that simulates terminal behavior in tests without using live transport or session state. `docs/automation-design.md` → [automation](automation.md)
- **terminal_replies_owned_by_backend** (aka backend-owned replies, reply suppression) — Flag that tells the frontend the backend owns terminal protocol replies generated while parsing output. `crates/festerm-session/src/lib.rs::terminal_replies_owned_by_backend` → [sessions](sessions.md)
- **traceability** (aka validation graph, requirement map) — Machine-readable mapping between requirements, ADRs, test cases, and manual evidence used to validate changes. `validation/README.md` → [automation](automation.md)
- **WARP** (aka Microsoft Basic Render Driver, WARP raster) — Windows software rasterizer used for native validation and performance comparison for the terminal renderer. `validation/windows-warp/README.md` → [desktop-platform](desktop-platform.md)
- **workflow bundles** (aka automation bundle, immutable bundle) — Versioned automation package whose manifest, modules, and parameter schema are frozen before approval and execution. `docs/automation-design.md` → [automation](automation.md)
- **workspace restoration** (aka metadata-only restore, restored workspace) — Metadata-only restoration of tabs and layout without replaying host grants or recreating a live transport until user action. `README.md` → [app-shell](app-shell.md)
