- **host inventory** (aka authorized inventory, session inventory) — Protected list of sessions and host state that a client may query after explicit host authentication. `docs/host-protocol.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host service** (aka shared host service, background host) — Configured local service that authenticates, inventories, and routes remote host sessions and terminal attachments. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)
- **host-based Dev Tunnel** (aka HOST tunnel, host tunnel) — Host-oriented remote-access flow that authenticates a configured host service and then creates or attaches to shell sessions. `docs/adr/0084-host-based-dev-tunnels.md` → [tunnels-enterprise](tunnels-enterprise.md)

- **local PTY** (aka native PTY, local shell PTY) — Local pseudo-terminal used by a native local session to own a shell process and its I/O stream. `docs/adr/0025-native-local-session-persistence-daemon.md` → [sessions](sessions.md)
