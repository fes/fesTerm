# Which esctest2 tests fesTerm is held to.
#
# esctest2 has 559 test methods and we pass 110 of them today; #193 tracks the
# phases that change that. A suite that is mostly red on every run gets
# ignored, so this file is the contract instead: everything listed here must
# pass, and a regression in any of it fails CI.
#
# Entries are Python regexes matched against the full test name
# (`ClassName.test_Method`). A bare class name enables the whole class.
# Individual tests inside an enabled class can be excluded in
# `esctest2-skip.txt`, which requires a reason for each.
#
# Anything not listed here is not enabled yet. Do not read that as "passes but
# is not run" - most of the rest of the suite cannot even be *observed* until
# DECRQCRA exists, because that is the only way esctest reads the screen.
#
# Run it with `scripts/run-esctest2.sh`, or survey the whole suite with
# `scripts/run-esctest2.sh --everything`.
