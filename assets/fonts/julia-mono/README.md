# JuliaMono terminal font

fesTerm bundles four unmodified static faces from **JuliaMono 0.63.2**:
Regular, Bold, Regular Italic, and Bold Italic.

Source: <https://github.com/cormullion/juliamono/releases/tag/v0.63.2>.
`manifest.json` records the official archive digest and per-file provenance.
JuliaMono is distributed under the SIL Open Font License 1.1 and reserves the
font name `JuliaMono`; fesTerm does not modify or subset these files.

The weekly bundled-font workflow monitors official JuliaMono releases and
opens or updates a family-specific review issue. Updates require deliberate
asset, metric, rendering, and license review; they are never merged automatically.
