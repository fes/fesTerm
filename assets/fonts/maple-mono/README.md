# Maple Mono terminal font

fesTerm bundles four unmodified static faces from **Maple Mono 7.9**:
Regular, Bold, Italic, and Bold Italic. These are the plain upstream TTF files,
not Nerd Font or CJK-expanded builds.

Source: <https://github.com/subframe7536/maple-font/releases/tag/v7.9>.
`manifest.json` records the official archive digest and per-file provenance.
Maple Mono is distributed under the SIL Open Font License 1.1 and reserves the
font name `Maple Mono`; fesTerm does not modify or subset these files.

The weekly bundled-font workflow monitors official Maple Mono releases and
opens or updates a family-specific review issue. Updates require deliberate
asset, metric, rendering, and license review; they are never merged automatically.
